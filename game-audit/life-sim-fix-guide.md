## 1. 测试方法与覆盖度声明（重要，必须保留在最终报告里）

### 1.1 关于"玩超过 1 万局"

**未以浏览器逐局点击的方式完成 1 万局，而是改为调用游戏自带的引擎模块做无头对局。** 原因：浏览器实测单局约 9 分钟，1 万局需 60 天以上，不可行。替代方案的等效性：

| 维度 | 浏览器逐局 | 本审计的无头对局 |
|---|---|---|
| 使用的逻辑 | 游戏引擎 | **同一份游戏引擎**（`engine.js` + `data/*.js`，未改一行） |
| 局数 | ≤ 数局 | **6 万局 × 2 轮 + 定向 7 千局 = 13.7 万局** |
| 抉择覆盖 | 人工，有偏好盲区 | `autoChoose`（引擎自身权重）+ 强制焦点/主动消费两种策略 |
| 内容表覆盖 | 抽样 | **100% 静态比对（见 §2 B 档）** |
| 局限 | — | 无法度量 UI 渲染、文案排版、点击手感 |

若需要 UI 层缺陷，需另做人工/浏览器抽样测试；本文不声称覆盖 UI。

## 3. P0 详解与修复方案

### D-01 1981 年前预期寿命：线性外推 + 缺失三年困难时期

**当前行为**（`data/development.js`）
```js
lifeExpectancy: [[1981,67.77],[1990,68.55], ...]   // 锚点表 1981 年才开始
if (year < 1981) lifespan = (isMainland ? 67.77 : lifespan) - (1981 - year) * .38;
```
即 1950 年 = 67.77 − 31×0.38 = **55.99 岁**，一条完美直线。

**实测**（每格 60 种子，同-sex 固定，取"出生年对应队列"的模型预期寿命）

| 出生年 | 北京 | 广州 | 焦作 | 应有量级 |
|---|---|---|---|---|
| 1950 | 57.2 | 57.0 | 56.3 | 35–45 |
| 1960 | 61.0 | 60.8 | 60.1 | **历史低谷 ~44** |
| 1970 | 64.8 | 64.6 | 63.9 | 63–65 |
| 1980 | 68.6 | 68.4 | 67.7 | 67.8（**已准确**） |
| 2020 | 79.1 | — | — | 77.9–79.0（已准确） |

→ 1981 年后精度很好（1980 实测 68.4–68.6 vs 官方 67.8），**问题全部集中在 1981 前的直线段**，且完全缺失 1958–1961 的异常下探。玩家只要出生在 1950–60 年代，就会明显觉得"那个年代我太平顺了"。

**修复**：删除线性外推，改为把历史锚点直接并入 `MAINLAND_OBSERVED.lifeExpectancy`。

```js
// data/development.js — MAINLAND_OBSERVED.lifeExpectancy 替换为
lifeExpectancy: [
  [1950, 43.8], [1954, 49.0], [1957, 53.0],
  [1959, 47.0], [1960, 43.8], [1961, 41.0],   // 三年困难时期低谷
  [1963, 55.0], [1965, 58.0], [1970, 63.0], [1975, 65.5],
  [1978, 67.0], [1981, 67.77], [1990, 68.55], [2000, 71.40],
  [2010, 74.83], [2020, 77.93], [2024, 79.0], [2025, 79.25],
]
// 并删除： if(year<1981) lifespan = (isMainland?67.77:lifespan) - (1981-year)*.38;
```
> 口径说明（务必同时写进代码注释与 `modelOnly`）：1982 年前官方无连续生命表。表内 1950–1978 数值取自联合国《世界人口展望》/ 原国家计生委常用回顾口径的**量级**，1959–61 的谷值按死亡人口超额幅度定性设置。请在合并前用 `china-baseline-data.md` 的"未获取清单"补录正式出处，并在 UI 上对 1982 年前年份显示"历史估算"标签。`BASE §9-1`、附「未获取清单-1/5」。

**回归断言**
```
for by in [1950,1955,1960,1965,1970,1975,1980]:
  LE(by) 单调性：除 1959<=y<=1962 区间外，LE 必须随年份不降
  LE(1950) < 48 且 LE(1960..1962) < LE(1957)        # 谷值存在
  LE(1980) in [66,69] 且 LE(2025) in [78.5,79.8]     # 不许破坏已有精度
```

### D-02 婴幼儿死亡率反向移动，且低估 4–5 倍

**实测**（同上受控探针，`childMortality` = 每局"5 岁以下子女死亡"发生率）

| 出生年 | 1950 | 1960 | 1970 | 1980 | 1990 | 2000 | 2010 | 2025 |
|---|---|---|---|---|---|---|---|---|
| 游戏 | **6.20%** | **6.76%**↑ | 4.36% | 3.50% | 2.50% | 1.69% | 0.71% | 0.32% |
| 真实 5 岁以下死亡率量级 | ~25–30% | ~25% | ~15% | ~8% | ~5% | ~3.7% | ~1.6% | ~0.6% |

两个问题：① **1950→1960 上升**，与 D-01 的直线外推同源（死亡概率来自 `expectancyFactor = exp((79.5-LE)/10)`，LE 被高估 → 婴幼儿被"救活"）；② 全期低估 4–5 倍。6 万局中只有 **16 局**（0.027%）失去 5 岁以下孩子，而 1950 年代一个四口之家夭折概率应在 30–50%。这是"历史沉浸感"最致命的一条：**那个年代的玩家几乎不会经历丧子之痛**。

**修复**：`engine.js::mortality()` 的婴幼儿分支不要只由 `expectancyFactor` 推导，改为独立年龄别表：
```js
const U5_MORT = [[1950,.29],[1957,.24],[1960,.26],[1963,.20],[1970,.15],
                 [1980,.081],[1990,.050],[2000,.037],[2010,.016],[2020,.0075],[2025,.006]];
// 新生儿/1-4岁分支： p = interpolateAnchors(U5_MORT, year) * sexAdj * urbanAdj
// urbanAdj: 农村 ×1.35, 城市 ×0.75（1990 年前 ×1.6 / ×0.6）
```
并把 `mortality()` 中作用于 <5 岁的 `expectancyFactor` 项移除，避免与 D-01 双重修正。

**回归断言**：`childMortality(1950) >= 0.20`、`<= 0.05 (2020)`、**全序列单调不升**；`OWN_CHILD_DIED_BEFORE_5` 在 1950–75 出生队列中应达 **150–350 / 1000**（现在是 0.5）。

### D-03 1966–1969 高考停招：只有"延迟"，没有"取消"

**当前行为**：`education.js` 的大学入学只受年龄与分数驱动，`china-law.js::educationAdmissionRoute / examUniversityTier` 未按年份封锁统考通道。历史事件表里有"高考中断"的**文案**，但没有闸门。

**实测**（4,000 局定向：筛出"18 岁落在 1966–1969"的队列 200 人）
- **111 / 200 人最终获得大学及以上学历**（55.5%，与正常年份几乎无差别）
- 样例：`{"by":1948,"edu":"masters","uniAge":31}`、`{"by":1950,"edu":"university","uniAge":32}`
  → 引擎只是把他们推迟到 1977 年后入学，但**"恢复高考时已 29–31 岁还能读到硕士"**在制度与年龄上都不成立。

**修复（三级闸门，缺一不可）**
1. **硬封锁**：`1966 <= admissionYear <= 1969` → 统一招生考试通道不可用（`route = 'suspended'`）。
2. **替代通道**：`1970 <= admissionYear <= 1976` → 仅"推荐工农兵学员"，录取概率 ≤ 正常年份 ×0.3，且要求 `政治条件`（团员/基层推荐）；专业限工农类。
3. **恢复闸门**：`admissionYear == 1977` → 录取率硬性 `≤ 0.048`（1977 实际 4.8%，570 万人报考录取 27.3 万）；`admissionYear == 1978` ≤ 0.07。恢复高考后大龄入学者**上限硕士**，且 `uniAge > 30` 时硕士概率 ×0.15。
4. **成年后入学总闸**：任何 `uniAge > 35` 的全日制入学改判为"成人高等教育/自考"，学历等级最多 `university`，不计入全日制校友/校招收益。
`BASE §9-3`（高考录取率上限）、`BASE §9-4`（名校概率）。

**回归断言**
```
cohort = lives with (birthYear+18) in 1966..1969
assert count(c.edu in ['university','masters','phd'] and c.uniYear in 1966..1969) == 0
assert P(edu>=university | 1977 届) <= 0.06
assert count(uniAge > 35 && 全日制) == 0
```

### D-04 港澳台预期寿命 1985 年后永久冻结

**当前行为**（`data/development.js:44`）
```js
let lifespan = isMainland ? interpolateAnchors(MAINLAND_OBSERVED.lifeExpectancy, observedYear)
                          : ({taiwan:81, hongkong:85, macau:83.5}[location.region] || 79.25);
```
非大陆是**一个常数**，再叠加上面的线性段（该项对非大陆不生效，因为 `isMainland` 为假但 `year<1981` 分支仍在跑），结果实测：

| 出生年 | 1950 | 1960 | 1970 | 1980 | **1985 → 2026** |
|---|---|---|---|---|---|
| 香港 | 74.3 | 78.1 | 81.9 | 85.7 | **86.1（恒定）** |
| 台湾 | 69.8 | — | — | 81.3 | **81.6（恒定）** |
| 澳门 | 72.6 | — | — | 84.1 | **84.4（恒定）** |

→ 1985 年后香港玩家**永远**活到 86.1 岁，无论 1990 还是 2026 出生；同时 1950 年给香港 74.3 岁（真实约 61–65），**早期高估、后期不动**。

**修复**：三地各建观测锚点表，与大陆走同一条 `interpolateAnchors` 通路，并删除 `year<1981` 线性段对非大陆的残留影响。
```js
REGION_OBSERVED = {
  hongkong: [[1950,61.8],[1961,67.8],[1971,72.1],[1981,76.6],[1991,78.9],[2001,81.6],[2011,83.9],[2023,85.5]],
  taiwan:   [[1950,58.0],[1961,65.5],[1971,69.7],[1981,73.5],[1991,76.0],[2001,78.5],[2011,80.0],[2023,80.6]],
  macau:    [[1950,60.0],[1961,67.0],[1971,71.5],[1981,75.5],[1991,78.0],[2001,80.5],[2011,82.5],[2023,83.6]],
}
```
> 同样标注为待补录口径（`BASE` 附「未获取清单」已列澳门/台湾缺口），合并前补联合国 WPP / 各地统计处出处。

**回归断言**：三地 LE 序列在 1985–2026 **必须逐年严格递增**；`LE(2023) ∈ [79,86]`；`LE(1950) < 65`。

### D-05 四地收入压缩到同一档（违反基准硬约束 15）

**当前行为**：`cityFactor` 是一组按 location id 正则匹配的**阶跃系数**，最大放大 1.0、最小 0.46，因此四地 `typicalIncome` 被拉平。

**实测**（2026 年开局，`typicalIncome`）

| 地区 | 游戏内 | 真实人均 GDP 相对量级 |
|---|---|---|
| 大陆（样本均值） | ¥66,602 | 1.0 |
| 台湾 | ¥75,184（**1.13×**） | ≈ 4 |
| 香港 | ¥85,121（**1.28×**） | ≈ 6 |
| 澳门 | ¥81,533（**1.22×**） | ≈ 8 |

`BASE §9-15` 明确规定：**"四地同池必须乘地区系数"**，并给出参考比（以河南 GDP=1 时 台湾≈4、香港≈6、澳门≈8）。同时 `prosperity` 区间高度重叠（大陆 0.51–0.942 与 澳门 0.803–0.892 互相包含），玩家选任意一地都感知不到生活成本差异；非大陆的 `sourceIds` 为 **空数组**，即三地收入无来源标注。

**修复**

```js
// 1) 收入侧：把地区系数从 cityFactor 里剥离，作为区域级乘数（不与城市系数相乘塌缩）
const REGION_INCOME_FACTOR = { mainland:1.0, taiwan:3.9, hongkong:5.8, macau:7.4 };  // 2025 口径

// 3) 住房：homeTerms 的 totalPrice 尺度改用「当地住宅均价 × 面积」而非 prosperity
//    全国均价 ≈10,005 元/㎡；一线/新一线/二线/三线 分别 5.5 / 2.6 / 1.3 / 0.75 × 全国
// 4) 给 hk/tw/mo 的 location 补 sourceIds，禁止留空
```
`BASE §9-6`（工资口径：私营 71,590 / 非私营 129,441 / IT 非私营 248,752）、`§9-7`（收入中位数 = 均值的 83–85%）、`§9-15`。

### D-06 亲属死亡率对年代 / 地区 / 性别全盲

**当前行为**：`engine.js::familyYear()` 用一个**全局平坦 hazard**推进亲属年龄，与 `world`、`year`、`location`、`sex` 均无关，并硬顶 `age >= 113`。

**实测**（母亲死亡年龄，按玩家出生年分组）

| 玩家出生年 | 1950 | 1960 | 1970 | 1980 | 1990 | 2000 | 2010 | 2020 |
|---|---|---|---|---|---|---|---|---|
| 母亲死亡年龄均值 | **80.89** | — | — | — | — | — | — | **81.19** |
| 父亲死亡年龄均值 | 81.0–81.4（全期不变） | | | | | | | |

→ **跨越 70 年、跨越四地，母亲都活到 ~81 岁**。真实世界：1950 年中国女性平均预期寿命不到 45 岁，2024 年女性 81.9 岁、性别差 5.5 岁（`BASE §9-1/2`）。同时父/母死亡年龄几乎相同 → **5.5 岁性别差在亲属身上完全不存在**，而玩家本人的 `expectancy` 却有性别差，属于引擎内自相矛盾。

**修复**：亲属推进复用**本人**的死亡模型，只是把"队列年份"换成亲属自己的出生年。
```js
// engine.js::familyYear(life, person)
const cohortYear = life.year - (person.age - (person.startAge ?? 0));   // 亲属自己的出生年
const prof = profileFor(life.location, person.sex, life.world, cohortYear);  // ← 关键：带年份与性别
const p = mortalityFor(person.age, prof, { chronic: person.chronic ?? false });
person.alive = !chance(life, p);
```
- 使用 `person.sex` → 自动继承性别差；
- 使用 `cohortYear` → 自动继承 D-01/D-04 修复后的历史曲线；
- 删除 `113` 硬顶，改为 `person.age > Math.round(prof.lifeExpectancy * 1.35) ? 1 : p`；
- 父母初育年龄改为队列相关（见 D-09）。

**回归断言**
```
meanMotherDeathAge(1950 cohort) < meanMotherDeathAge(2020 cohort) - 15
meanDeathAge(father) - meanDeathAge(mother) in [4.0, 7.0]        # 5.5 岁性别差
meanMotherDeathAge(1950, hongkong) < meanMotherDeathAge(2020, hongkong)
max(deathAge) <= 110 且 >105 的例数占比 < 0.5%
```

### D-07 兄弟姐妹数无视生育政策分期

**当前行为**
```js

```

**实测**：1950–79 队列均值 **2.49，独生子女 0 例**；1980–2015（一孩政策）与 2016–2025（二孩/三孩）**分布完全相同**（均值 1.0、上限 2）。触发 `SIBLING_COUNT_IGNORES_ONE_CHILD_POLICY` 30/1000。

→ 双重失真：① 一孩时代之前"必然有 1–3 个兄弟姐妹"，而 1970 年 TFR 已降到 4.8、1979 年已 2.75，城市头胎后普遍只生一个的年代里玩家不可能"必定 2 个以上"；② 2016 年后放开二孩、2021 年放开三孩，**分布却与一孩时代一致**，等于宣布政策不存在。

**修复**（按出生年分段的 sibling 分布，均值对齐 TFR × 存活率）
```js
const SIBLING_DIST = [
  { to:1970, w:[.10,.18,.24,.22,.16,.10] },  // 0..5 个，均值≈2.5（1970 TFR 4.8，婴幼儿死亡率高 → 存活同胞更少）

  { to:2015, w:[.24,.55,.17,.03,.01,null] }, // 一孩政策：独生子女≈55%，均值≈1.0；城镇执行更严 → 城镇 w=[.30,.60,.09,.01]

];
// 城乡分离：urban 取更严一档；农村（1980–2015）允许"头胎为女孩可生二孩" → w=[.18,.50,.27,.05]
```
> 依据 `BASE §9-14`（0–17 岁养育成本 53.8–58 万 → 抑制二孩意愿）、TFR ≈1.0（`BASE` 人口条目）。

**回归断言**：`meanSiblings(1985 出生, 城镇) in [0.8,1.2]`；`P(siblings==0 | 1990–2010 出生) > 0.40`；`meanSiblings(2020 出生) > meanSiblings(2000 出生)`；**独生子女在 1980 前队列中必须存在**（>0）。

### D-08 结婚年龄无衰减闸门（p95 = 71 岁，最大 102 岁）
60,000 局 `marriageAge`：均值 37.49 / p50 29 / p95 **71** / max **102**。romance 候选窗口固定 18–48 且**无"随年龄递减的匹配概率"**，于是 70 岁仍能正常初婚（引擎未排除"此前从未恋爱"的路径叠加）。
**修复**：引入匹配衰减与初婚/再婚区分。
```js
const firstMarriageHazard = (age, cohort) => base * Math.exp(-Math.max(0, age - idealAge(cohort)) / 6);
// idealAge(cohort)：1950s=20 → 1980s=24 → 2000s=26 → 2020s=29（BASE §9-12 初婚年龄窗）
// 硬闸：age > 55 → 初婚概率 = 0（只允许再婚，且需 partner 曾婚史）
```
**断言**：`p95(marriageAge) < 40`、`max < 62`、`mean(初婚) in [24,30]`；35 岁以上未婚者应高概率触发 `marriage-pressure`（当前 43.2%）。

### D-09 生育无年龄闸门 + 母亲年龄跨年代恒定
- `firstChildAge` p50 35 / max 49；`MATERNAL_AGE_TOO_HIGH_FOR_COHORT` 55.5/1000，因为母亲初育年龄对所有队列都是 `uniform(24, 37)`。
- `BASE §9-13`：**45 岁以上自然妊娠概率 < 1%，50 岁以上受孕应判为不可能**。
**修复**
```js
const FEC = a => a<20?.55 : a<25?1.0 : a<30?.92 : a<35?.68 : a<40?.30 : a<45?.04 : a<50?.006 : 0;
// 队列化母亲初育年龄： motherFertBase = 20 + clamp((cohortYear-1950)/72*8, 0, 8)  // 1950→20岁, 2020→28岁
```
**断言**：`P(childbirth | motherAge > 49) == 0`；`P(motherAge 45–49) < 0.01`；母亲死亡/生育分布随玩家出生年单调移动。

### D-10 子女可先于认识伴侣出生（36.3/1000）
`engine.js` 的生育检查只验 `partner?.alive`，未验"伴侣关系建立早于受孕年"。
**修复**：`if (life.family.partner?.sinceYear > life.year) return false;` 并在生育前写 `partner.sinceYear`。另需补：单身生育（2020 年代后按地区允许，权重 ≤0.02）。
**断言**：`CHILD_BORN_BEFORE_MEETING_PARTNER == 0`。

### D-11 经济闭环不平账：终身收入 62% 至死未花掉
**实测 3,000 局**（`totals.earned` / `totals.spent` / `netWorth()`）

| 指标 | p10 | p50 | p90 |
|---|---|---|---|
| 净财富 / 终身收入 | 0.68 | **0.88** | 1.04 |
| 支出 / 终身收入 | 0.21 | **0.38** | 0.58 |
| 未消费占比 | 0.42 | **0.62** | 0.79 |

均值终身收入 ¥6,448,149，均值净财富 ¥5,948,416。另 `CASHFLOW_DOES_NOT_RECONCILE_TO_NETWORTH` 18.3/1000（存在完全对不上账的局）。
根因：`economy.js` 只做"收入 − 生活成本 + 投资回报"，**退休期没有资产消耗、没有遗产转移、没有医疗自付冲击的强制支出**，于是财富单调累积到死。这在体验上把"退休"变成了纯收益期，与中国养老现实（替代率 37–41%，`BASE §9-9`）相反。
**修复**
```js
// 1) 退休期资产消耗：支出基准从「在职收入」切到「养老金 + 资产释放」
const drawdown = retired ? Math.max(0, netWorth*0.06) : 0;     // 6%/年资产消耗（25年余命）
// 2) 医疗自付冲击：60 岁后每年 chance=0.10*(1+age-60)*0.02 → 支出 = typicalIncome*[0.5,3]
//    （重疾自付中位 ≈ 8–13 万，BASE 未获取清单需补录官方口径后再定标量）
// 3) 遗产：死亡时 netWorth 按比例转给存活子女/配偶，本人"终局财富"应显示为可继承额
// 4) 断言级修正：投资回报必须扣除通胀（用 incomeIndex 作物价代理），否则 returns 是真实增益
```
**断言**：`median(净财富/终身收入) in [0.10, 0.35]`；`median(支出/终身收入) in [0.70, 1.05]`；`CASHFLOW_DOES_NOT_RECONCILE == 0`。

### D-12 生活成本挂钩"地区典型收入"而非本人收入
`economy.js` 的 `scale = max(1000, life.profile.typicalIncome)`，且 `living = scale*(house?0.35:0.45)`。后果：
- 月入 3 千与月入 8 万的人**生活成本相同** → 高收入者储蓄率被系统性放大（直接喂大 D-11）；
- 无房者与有房者只差 0.10 的系数，**等于没有租金**。实测 28 岁有业者：按揭房可得率仅 **6.9%**（原因分布：`积蓄不足` 1,808 / `就业或还款能力不足` 613），全款房 **0.0%**，而购车 90.3% → **买得起车买不起房**，与实际完全颠倒。
**修复**
```js
const ownBase = clamp(life.income || 0, typicalIncome*0.45, typicalIncome*2.2);
const housingCost = life.assets.house>0 ? ownBase*0.10                      // 物业+折旧+利息
                    : urban ? typicalIncome*0.30                             // 市场租金（重点：无房要付全额租金）
                            : typicalIncome*0.12;                            // 农村自建房
const living = ownBase*0.28 + housingCost + foodCare(ownBase);
```
并把 `homeTerms.totalPrice` 换成 D-05 的「均价 × 面积」模型，使房价收入比落到：一线 25–40×、全国中位 9–10×（住宅均价 ~10,005 元/㎡，`BASE`）。同时补**个税 + 五险一金个人侧**（当前完全缺失，是高储蓄率的第二根因）。
**断言**：`P(自购住房 | 30–39 岁) in [0.35,0.60]`（对齐真实城镇自有率）；`car 拥有率 > house 拥有率` 必须为假；`median(税后到手/税前) in [0.72,0.88]`。

### D-13 「自动抉择」不覆盖焦点与消费，与玩家预期不符
`autoChoose()` 只做 `weighted(options)` → `choose()`，**从不 `setFocus`、从不 `purchase`**（`getShopItems` 在自动流中一次都没被调用）。实测两种策略的终局差异：

| 策略 | 终身收入 | 净财富 | 死亡年龄 | 自有住房率 |
|---|---|---|---|---|
| 仅 autoChoose | ¥4,530,436 | ¥3.45M | 80.2 | **0%** |
| autoChoose + focus=work | **¥6,804,617（+50.2%）** | ¥6.32M | 82.1 | — |
| autoChoose + 主动消费 + focus=work | — | ¥13,996,944 | — | **95.3%** |

即：内置"自动"按钮**默默放弃了人生最强杠杆**，还把玩家引导成"终生无房"。
**修复（二选一，必须做其一）**
- A. 把「自动抉择」改名为「自动应答」，并在按钮旁提示"焦点与消费需手动安排"；
- B. 新增「托管整段人生」：每轮自动 `setFocus`（按 5 档人生策略预设：奋斗/平衡/健康/家庭/学业）+ 按可负担规则消费（房→车→投资优先级）。
推荐 **B + 保留 A 的旧按钮**。**断言**：托管策略的 `homeOwnership in [0.4,0.8]`、终身收入差异 < 20%（说明预设之间是取舍而非碾压）。

### D-14 历史事件 156.3/1000 无任何机械效果
`data/history.js` 中静态缺 `effects` 的只有 `retirement-reform(2025)`，但实测**每局约 1/6 命中的事件不产生任何可观测状态变化**：这些事件的 `effects` 写的是"对某类人群"的乘数，而触发条件与玩家状态永不相交（例如"下岗再就业补贴"却要求 `job.sector==='soe'` 而该 sector 字段不存在）。
**修复流程**（AI 按此实现，勿逐条手改）
```
1. 给 history-runtime.js 加 effect 探针：apply 前后做 state diff，diff 为空则记录 event.id
2. 跑 20,000 局，输出 "命中≥50 次且 diff 恒空" 的事件清单
3. 对清单中每个事件，二选一：
   (a) 补真实传导：把条件改为引擎里确实存在的字段（如 flags.education、job.sector 需先在 career.js 落地）
   (b) 若确属"背景氛围"，加一条 happiness/householdIncome 的 ±0.5~3 点微效果，避免零反馈
```
**断言**：`HISTORY_EVENT_HAS_NO_MECHANICAL_EFFECT < 20/1000`，且**每个 era 至少有 1 个改变收入、1 个改变教育通道、1 个改变迁移成本的事件**。

### D-15 历史事件错配地区（25.3/1000）

### D-16 零杠杆抉择（含"接受自由文本却毫无作用"）
整局分叉实验（同种子克隆 → 强制单一选项 → 跑完整局 → 指纹比对）：

| 抉择 | 选项数 | 整局完全一致 | 结论 |
|---|---|---|---|

**断言**：`exp3-divergence.mjs` 对全部抉择类别要求**宽松指纹差异率 ≥ 60%**；`reflect` 需在 `life.journal` 有写入。

**断言**：`max over categories of ΔdeathAge(p95) <= 4.0`。

### D-18 农业与制造业岗位从未可达（就业史主体缺失）
66 个 `CHINA_JOBS`（定义在 **`data/china-society.js:131`**，用 `J(...)` 构造器；`career.js` 只是逻辑模块、不含岗位表）全部继承构造器里的 `modelKind:'illustrative-job-and-salary'`（66/66）。6 万局中从未被任职的岗位：`farmer`、`livestock/livestock`、`fishery`、`agricultural-tech`、`cooperative`、`state-factory`、`factory-operator`、`textile-worker`、`welder`、`mechanic`。
→ 1978 年中国第一产业就业占比 **70.5%**，2022 年仍有约 23%；一个模拟 1950–2026 的游戏，**没有任何一局出现农民或工人**。这是最容易被玩家一眼看穿的失真。

**已定位的根因（不是"缺岗位"，数据里岗位是有的）**
```js
// career.js:59  candidateCareers()
return CHINA_JOBS.filter(job => permittedCareer(life, job) && !['self-employed'].includes(job.sector));
//                                                              └── 这一句把 5 个 self-employed 岗位永久排除，
//                                                                  其中含 farmer(种植农户)/livestock(畜禽养殖)/cooperative(合作社)
```
配套事实：岗位表**已**带 `{urban:false}` 与 `agriculture` 门类，引擎也**确实**按城镇化曲线抽样户籍
（`engine.js:180` `urban = chance(life, urbanization ?? .55)`），`career.js:45` 有 `job.urban===false && life.urban → 拒绝`。
即"农村玩家存在、农村岗位存在"，但 `self-employed` 排除句砍掉了务农主线；`factory-operator / textile-worker /
state-factory / mechanic` 不属 `self-employed`，说明**还有一处**把它们挡在 Offer 之外（怀疑方向：`welder` 需
`professional-license` 资格而资格链从未发放；其余需实测）。
**因此第一步不是改数值，而是跑诊断**：对 5,000 局逐岗位打印 `permittedCareer()` 的**第一个失败子句**，
输出"岗位 × 失败原因 × 命中次数"表，据此分诊。

**修复**
1. 岗位池按年代重建：`CHINA_JOBS` 增加 `eras` 与 `urbanOnly` / `ruralOnly` 字段；
2. 出生地/户籍决定初始池：`urban===false` 时首职从农业岗抽取，权重要随 `urbanization` 曲线衰减（1978 年 0.71 → 2025 年 0.15）；
3. 打通"农民工"迁移链：`rural → relocate(city)` 后 5 年内进入 `factory-operator/textile-worker/welder`，且**不得**直接跳到白领岗（当前 `state-factory` 等不可达说明职介链路缺失）；
4. 补 `coop → state-factory → 1992 后下岗/再就业` 与 `乡镇企业` 的历史路径（对应 D-14 的事件传导）。
**断言**：`P(ever_occupation in 农业/制造业 | 出生年 1950–1985) >= 0.45`；66 个岗位中**从未任职**的数量 ≤ 5。

### D-19 非大陆法规真空（且与养老金规则相互矛盾）
`china-law.js` 的 `legalMarriageAge / canStartEmployment / retirementRule / pensionMinimumYears` 对非大陆**返回 `null`**，引擎未做替代 → 无闸门（`MARRIAGE_LAW_GATE_NULL_NONMAINLAND` 18.3/1000）；但同一批非大陆玩家**又在领大陆养老金**（`PENSION_FROM_MAINLAND_RULE_IN_NONMAINLAND` 11.8/1000）。即"一边说这里没有法律，一边套用大陆社保"。
**修复**：补三地法规表，并让养老金分支按 `location.region` 选规则，禁止 `null` 落入"无校验"分支。
```js
// 参考口径（需在合并前用当地法源核实并写入 sourceUrls）：
// 台湾：婚姻最低 18 岁（2023 民法修正统一 18）；退休 劳基 60 / 劳退 63→65（2025 起每 3 年 +1）
// 香港：婚姻 18（16–21 需同意）；无强制性法定退休年龄；MPF 强积金 65 岁提取
// 澳门：婚姻 18；退休无统一法定年龄；社保养老金 65 岁
```
**断言**：`MARRIAGE_LAW_GATE_NULL_NONMAINLAND == 0`、`PENSION_FROM_MAINLAND_RULE_IN_NONMAINLAND == 0`；四地每局都有明确的婚姻最低年龄与退休规则。

### D-20 1985 年前名义价格 × 常数收入（两套货币概念混用）
`PRE1985_TUITION_NOMINAL_VS_CONSTANT_INCOME` 19.8/1000：学费/消费品用历史名义标价（如 1978 年大学学杂费数十元），而 `incomeIndex` 把 1978 年收入折算到"2025 元"口径（¥18,563），两者不在同一货币空间，导致**1978 年上学几乎免费、买房形同白送**。
**修复（二选一，推荐 A）**
- **A. 全内部统一为"当年真实元"**：所有表列名义价 + 收入按当年真实值；展示时再乘 `CPI_INDEX` 换算给玩家看；
- B. 全部相对化：价格改为"当年典型收入的倍数"（如 `tuition = income*0.02`），删除历史名义常量。
无论哪种，`china-law.js::tuitionModel` 需与之一致，并给 `1977–1993 公费/学杂制` 与 `1994 后并轨收费` 加分段（`BASE §9-6`、`china-law.js::studentLoanPolicy`）。
**断言**：对 `year<1985` 的每局断言 `tuition / 当年真实收入 <= 0.35` 且 `>= 0.0`，并且**同一局内不出现两套口径**（可用"名义值 ÷ incomeIndex ≠ 相对值"检测，脚本已在 `run-audit.mjs`）。

## 7. 先决条件：修好度量再修游戏

**这是本审计最重要的方法论产出。** 第一轮 6 万局的结论中有 5 条是校验器自身造成的假象（§1.4）。因此在做任何 P0 修复前，先给校验器加 3 个补丁：

1. **每个断言必须报告分母**。形如 `childLabor: 0` 的输出无效，必须是 `childLabor: 0 / 3943 次雇佣事件`。
   - 反例（本项目真实发生）：引擎在 `choose()` 内部完成雇佣/退休状态迁移，若只在 `advanceYear()` 边界做前后比对，`EMPLOYMENT_UNDER_16`、`JOB_ABOVE_OWN_EDUCATION_LEVEL`、退休金与退休年龄类检查会**全部静默失效并显示"0 异常"**。
   - 正确做法：在**每一次**引擎调用（`choose` / `autoChoose` / `advanceYear` / `purchase` / `relocate` / `setFocus`）之后各跑一次 `diffTransitions(prevState, state)`。
2. **年代/地区比较必须控制混杂变量**：固定 `sex`，每格 ≥ 30 种子（本次用 60）。单种子比较只能用于"结构不变量"，不能用于"趋势判断"。
3. **"死内容"判定要先核对数据结构**，并区分"引擎不可达"与"默认策略未触发"（`autoChoose` 不购物，故 0% 住房不是缺陷）。

补丁位置：`game-audit/run-audit.mjs`（已含 `diffTransitions` 与分母输出，可直接当模板）。

```js
const life = E.createLife({ locations, seed:'x1', world:'past', birthYear:1990 });
E.startLife(life);
while (life.phase === 'life') {
  if (life.pending) E.autoChoose(life);
  else { if (life.job) E.setFocus(life, 'work'); E.advanceYear(life); }
  // 每次引擎调用后跑一次 diffTransitions(prev, life) —— 见 §7
}
E.netWorth(life); E.summarize(life);
```
> `world` ∈ `past`/`now`/`future`；`now`、`future` 均自 2026 年起；`birthYear` 钳制 1950–2100；RNG 由 `seed` 完全决定（可复现）。`world` 仅被 `engine.js`、`history-runtime.js`、`data/development.js` 三处读取——这是"同一份 2026 数据套用到三个世界"的根源（D-01/D-04/D-05 的共同上游）。
