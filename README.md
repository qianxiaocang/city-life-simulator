# 14亿分之一 · 城市人生

一个原创实现的中国城市人生模拟游戏，提供简体中文、繁体中文、英文。出生地与迁居范围限定在中国大陆、台湾、香港、澳门的城市和生活区域。页面与游戏代码均在本地运行，可以作为纯静态网站部署。

## 直接体验

- 从仓库克隆源码后，安装 Node.js 20 以上版本，运行 `npm install`、`npm run dev`，默认打开 `http://localhost:4173/`。
- 运行 `npm run build` 生成 `dist/standalone.html`（可单文件打开）和 `release/city-life-simulator-v1.3.0.zip`（可上传到静态网站根目录）。构建产物由本地生成，不提交进源码仓库。

详细的云服务器、Docker和Nginx步骤见[部署说明](<部署说明.md>)。

## 已实现的核心玩法

随机出生、家庭和气质、四项状态、逐年事件与重大抉择、年度重心、升学与继续教育、求职晋升与创业、恋爱婚育、城市迁居、医疗与照护、退休、死亡与人生回顾。购房、购车、家居、继续教育和投资会在人生抉择中出现，资产与现金变化记入人生记录。首页设有追思馆预览；追思馆展示已完成人生的像素画卡片、年龄分段片段及完整记录。

可暂停、按1/2/4/8/12/16倍推进、快转至下次抉择、手动推进一年，或使用「托管人生」。年度进度条随倍速推进；「保持均衡」与其他今年重心同列。死亡后只有主动选择「放入追思馆」，这段人生才会进入当前浏览器的馆藏；最多保留最近12段。更换浏览器、网址或清理网站数据会失去这些记录。人物与家庭、所有命运和收入均为模拟。

这版保留参考游戏的主要循环，具体事件、参数、代码和像素场景为原创。此版本提供独立玩家的完整本地模拟与回顾；公共社区、付费通行证和跨设备云账号服务不属于本次静态版。

## 1.3 界面更新

首页简化为开始页面，语言与主题切换集中在首页。追思馆新增列表、像素片段、按年龄分段的详情、完整记录、烛光和留言；手机优先布局支持窄屏。游戏内的身份、家人、状态和资产集中在可展开的人生总览中；人生抉择以弹窗呈现，收藏的记录附像素画显示在「人生瞬间」。消费与投资改由人生抉择提供，现金及资产变动自动留痕。说明见[追思馆与移动端改版说明](docs/追思馆与移动端改版说明.md)，验证见[本轮验证记录](qa/verification-v1.3.md)。

音乐控制已改为可拖拽的全页面悬浮按钮，开启与关闭使用不同的背景色和动画，并支持系统减少动态效果设置。首页语言切换改为适合手机点按的弹出菜单，提供简体中文、繁体中文和英文。

游玩时可以收藏人生记录；这些记录会在死亡后优先进入追思馆的「人生瞬间」，相同的系统选片不会重复出现。像素画按记录文字选择场景和物件，并为每条记录绘制不同的日期色块。死亡画面的文字从整段人生记录中挑选个人经历与实际结局；在刚结束的人生详情中点击「写下你的话」可反复修改留言，离开详情页后便不能再改。

首页的出生时间入口只提供「过去」与「现在」，默认选择现在；已取消温和叙事切换。追思馆顶部汇总馆藏人生、累计岁月、最长一生、到过的地点、瞬间与烛光，人物详情展示身份、家庭和足迹。离世后可下载纪念照片；详情页的「重活一遍」返回首页。只有主动选择「放入追思馆」才会保存这段人生。[本轮验证与截图](qa/verification-14yi-memorial.md)。

## 1.1 模型更新

按出生月、性别与岗位计算大陆退休；中考/高考模拟分决定可选学校；公私立和专本科分别计算学费、资助与助学贷款；66类职业含公务员/教师等考试准入；12类家庭文化抉择；100条1950—2026国内、地方与全球事件按日期和居住地生效；现金不自动负数，房贷与助学贷款分账；住房、车辆、家居与教育支出、投资渠道随年代开放。

[模型算法与版本说明](docs/模型算法与版本说明.md)记录九项变更、来源、运行顺序、存档迁移与适用边界；[审计修复报告](docs/审计修复报告.md)列出6万局回归的实测分母与未达标项。另有[法律教育资料](docs/中国法律教育资料.md)、[社会职业消费资料](docs/中国社会职业消费资料.md)、[历史事件资料](docs/历史事件资料.md)。这些资料保留在项目文档中，不占用游戏界面。

九年义务教育为小学与初中；大陆一般就业最低16岁，16—17岁适用未成年工保护。没有工作不能普通贷款是游戏的保守规则，不是普遍法律禁令。历史事件是100条选编，并未穷尽每个城市的地方志。港台澳尚未核实的学制/退休/价格采用明确标注的独立模型，不套用大陆法条。

## 开发与构建

```sh
npm install
npm test
npm run dev
npm run build
```

`npm run build` 生成带有打包脚本的 `dist/index.html`、单文件 `dist/standalone.html`、部署ZIP、源码ZIP及SHA256校验。`npm run dev` 会先构建再启动本地预览。构建无需运行研究快照或调用原网站接口。开发服务器可用 `--host 0.0.0.0 --port 4173 --strictPort` 指定局域网访问。

## 项目结构

- `app/main.js`：界面、时间控制、浏览器保存、图片导出、音乐和原创Canvas场景。
- `app/engine.js`：纯逻辑、可序列化的确定性人生引擎。
- `app/i18n.js`：三语界面文本；事件文本同样提供三语。
- `app/data/locations.js`：城市目录与模型元数据。
- `scripts/`：静态开发服务器、构建器和城市数据生成器。
- `tests/`：引擎与地域完整性测试。
- `deploy/`、`Dockerfile`、`compose.yaml`：静态部署配置。
- `qa/`：实际浏览截图、导出图片示例与验证记录。

原游戏的研究快照与逆向笔记只保留在开发者本地，不进入公开源码仓库或网站发布包。
