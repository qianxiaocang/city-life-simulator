# 此生 1.2：模型算法与版本说明

资料核查截止 2026-10-25。本文件是继续开发时的入口，须与各专项资料文档及代码一并阅读。

## 本次九项改造

|问题|现有实现|事实与模型边界|
|---|---|---|
|退休年龄|大陆按出生年月、性别、原50/55/60岁类别计算渐进延迟；退休月进入抉择；养老金检查缴费年限|不是男女一律60岁。自主经营与港澳台使用明确标注的游戏参考，不冒充大陆法定规则|
|传统与家庭观念|12类情境覆盖春节团圆、升学、稳定工作、婚育、住房、人情、赡养、亲属互助；可接受、协商或拒绝|不把某种观念固定给所有中国人，也不强迫婚育|
|地方灾害|按发生日期、当时居住地筛选；伤病、住房损坏、现金损失和死亡独立结算；存档防止重复触发|出生地不是终身暴露地点。地级范围会稀释震中暴露；不把“受灾人数”当死亡率|
|中国发展史|1950—2026连续时代阶段及100条国内、地方、全球事件；全国城镇化/寿命有官方锚点，城市发展有轨迹调整|100条是选编，未覆盖每座城市的完整地方志；现代城市目录不复原历年边界|
|法律与升学|小学六年、初中三年；中考/高考模拟分决定可选学校，公私立与专本科学历分开；课程完成才授学位|九年义教不包括高中。一般岗位16岁可就业，16—17岁受保护；分数和费用为虚构参数，不是省市真实录取线|
|信贷与助学|现金不自动负数；普通信用仅向有稳定工作和偿付能力的成年人开放；困难学生申请审批后按年实际缺口借助学贷款|无工作禁贷是本作保守规则，不是普遍法律禁令。助学贷款有年代、地域、学段、额度和还款约束|
|工作类型|66类职业覆盖民营、国企、公务员、事业单位、农业和个体经营；学历与年代筛选；公考、教师等需准备、考核及接受岗位|考试概率、招聘条件和工资为简化模型；不是实地岗位招聘公告|
|全球影响|经济危机、贸易、公共卫生、气候和国际合作影响收入、市场、生活成本、学业与就业|海外灾害不直接把海外死亡率套给境内角色；未知未来没有伪造史实|
|中国式大额支出|现金购房/按揭、车、家具、家电、装修、子女读书、成人教育、照护等；存款、国债、股票、基金按年代开放|资产购置与日常消费分开；价格、收益、信用额度为游戏情景|

## 运行时结构与推进顺序

- `app/data/china-law.js`：生效年份、退休月份、婚龄、义教、助学贷款、模拟分段的纯函数与法律来源。
- `app/data/china-society.js`：三语文化情境、职业目录、商品、投资开放节点及来源。
- `app/data/history.js`：100条事件、55项历史资料来源、地域范围和时代阶段。
- `app/data/development.js`：全国已观察锚点、透明插值与城市发展模型。
- `app/education.js`：学段→考试→录取资格→资金方案→在读→毕业状态机。
- `app/career.js`：岗位筛选、考试准入、报名年龄资格、缴费年限、退休、婚龄和文化抉择。
- `app/economy.js`：年度收入、家庭/监护支持、学费、助学实际放款、生活开销、贷款偿付和消费。
- `app/history-runtime.js`：年内日期推进、当前居住地过滤、一次性暴露与持续背景。
- `app/references.js`：合并来源索引，界面事件和史料年表使用同一数据。
- `app/engine.js`：提供确定性随机数、年度推进及模块回调。`main.js`负责浏览器存档、年内进度、界面和交互。

每个年度先处理截止该时刻的历史事件与退休节点，重大抉择会暂停推进；然后结算年度重心、资金、家人、日常、健康和普通死亡风险。存活才进入下一岁/年，更新时代参数并处理毕业、考试结果、升学、求职等。学校学费在毕业之前按真实在读年数收取，不在入学时重复预扣整段费用。

历史事件按UTC日历计算年内比例，事件时刻标注北京时间，不受运行电脑时区影响。精度只有“年”的事件到年末汇总，不伪装精确到1月1日。出生当年出生前的事件不会生效。迁居前结算当下已有事件，未在场事件也记为已过去，防止事后迁居补抽灾害。伤亡只抽一次；经济背景不再次抽死亡。

普通就业要求不在全日制学校，大陆1986年后完成初中，且满足年龄与危险岗位限制。历史时期缺乏逐地制度细则的部分保留保守游戏安排。公考以报名时的年龄身份判断资格，次年结算不会仅因增一岁剥夺已经有效的报名；应届硕博放宽不适用于所有硕博持有人。考试、资格和后续岗位考察在年度粒度中简化，不保证录用。

早年儿童死亡风险已由医疗年代参数调整，不再额外乘一次寿命差距。个人健康、家庭阶层和慢病仍可影响风险。全国预期寿命只是出生人口的统计背景，不能当作角色固定死亡年龄或地方生命表。

## 数据口径

主要使用中国政府网、教育部、人社部、国家统计局、国家卫健委、应急管理部、地方政府、交易所等一手资料；全球背景使用联合国、世界卫生组织等中文原始资料。来源完整列于三个专项资料文件，游戏内也可打开链接。

全国城镇化锚点为1949、1957、1978、1995、2011、2023、2024、2025；寿命锚点含1981、1990、2000、2010、2020、2024、2025。历史收入统计口径变化，未把不同比较口径伪装成连续实际工资序列。当前收入是人民币体感购买力模型：全国发展指数、城市繁荣度/轨迹、职业倍数、经验和宏观背景共同决定，不等同当年的名义人民币工资或物价。

2026有已核实的政策/事件，但完整2026年年度统计尚未知，发展参数沿用最近完整统计或模型。2026-10-25之后不补造真实事件。“未来”模式只有明确的参数情景推演。“过去/现在”在已知史料终点后保持基准条件，没有未来预测数据。

港台澳作为独立适用范围保留，不借大陆法条证明当地义教、退休、考试或信贷制度。当地部分学制、考试、价格和退休目前是清楚标注的玩法模型，尚不是完整的本地法律历史复原。

## 存档兼容

继续使用版本1 JSON容器与同一本地存档键，人物 `rulesVersion=2`。缺失的出生月默认1月，原有工作补充职业元信息。助学贷款与房贷分账；有房产的旧住房债务保留；旧版负现金不再转换成普通借款，清零并在 `flags.legacyNegativeCash` 保存原值。这是为了终止旧模型自动生成无担保消费债务，旧存档财富会受迁移影响。旧的升学抉择重新进入考试/资金路线，不直接授予学历。

## 持续扩充方法

先查证原始资料，再新增有日期精度、地域范围、来源ID、三语事实摘要和模型说明的事件。先验证城市ID存在；避免在全国事件和地方事件重复叠加直接伤亡。同一来源描述范围不足时，不扩大到全国。不可把新闻事件数量当作统计风险频率。

新增职业需定义年代、学历、准入类型、部门和退休类别；新增商品需定义年代、年龄、资金、资产/子女等前提和冷却期。新增法律规则须注明生效期与地区，不能只改显示文本。

构建执行 `npm test` 和 `npm run build`。发布包含静态模块版、可直接打开的完整单文件版、源码和部署ZIP；运行游戏无需联网读取史料网页，点击出处链接时才访问外部网站。

专项文档：[中国法律教育资料](中国法律教育资料.md)、[中国社会职业消费资料](中国社会职业消费资料.md)、[历史事件资料](历史事件资料.md)。

高等教育若某学年学费实付不足，该课程年不计完成；`unfundedAcademicYears`按年记录，下一次教育处理会延后`endsAt`并重新打开资助安排。即使后来现金缺口消失，也不抹去已经未完成的课程。可保留模型学分休学工作，之后每年重新申请资金；合资格低收费衔接最多保留两年模型学分，必须继续完成剩余课程。这个规则是游戏对学业中断的简化，不冒充所有高校的学籍管理细则。未成年义教日常生活由家庭/监护支持，不受这条高教学费延期规则影响。

## 1.2 审计后新增

- 年度普通死亡采用同一随机风险预算累积，抉择分支不再因多调用随机数而重抽整段人生；迁居后成年风险将出生地与现居地的当年寿命背景各占一半。这是降低单次迁居过大寿命杠杆的游戏情景参数，不是实测移民死亡率。
- 历史记录显式保存事发时居住地、适用范围、出处和可观测机械影响。100条事件都有定向可达测试；年度收入、学业和迁居费用接受历史背景传导。
- 自由文本反思写入人生回顾；爱好、照护家人、社区参与对后续健康、关系或学习产生作用；升学、推荐与学校类型有不同后续结果。
- 「自动应答」只处理当下抉择；「托管人生」有奋斗、平衡、健康、家庭、学业五种策略，每年安排重心并在可负担范围内考虑住房、车辆和储蓄投资。
- 香港按强积金账户积累和提取建模，台湾和澳门按各地养老金资格做独立情景；四地就业及婚姻年龄闸门分开处理。早期年份缺完整法条链的区段仍标为模型。
- 2026界面显示「沿用截至2025年观测锚点的推算情景」及游戏货币口径；完整审计、已知未达标项和分母见[审计修复报告](审计修复报告.md)。
