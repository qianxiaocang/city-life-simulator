# 中国社会、职业与家庭经济：资料与实现约定

核查日期：2026-10-25。本文对应 `app/data/china-society.js`、`app/economy.js` 与相关测试。法律和教育细则另见 `app/data/china-law.js`、`app/education.js`。历史事件另由历史模块提供。

## 1. 事实、情景与模型的边界

资料可以证明某项制度或市场在何时存在，却不能证明任意家庭的价值取向、某个人的薪资或一次选择必然带来的幸福变化。本作将这些层次明确区分：

- `CHINA_SOCIETY_SOURCES` 保存可追溯的来源、事实摘要和稳定 ID；情景与商品通过 `sourceKeys` 引用。
- `CULTURAL_EVENTS` 是有资料背景的虚构选择，`modelKind` 为 `fictional-choice-with-source-context`。发生率、自动选择权重和属性变化是游戏参数。
- 岗位学历、收入倍数、消费价格、家庭支持比例、贷款通过门槛、回报率是简化模型，不是某年度全国实测分布，也不是银行报价。
- 全国统计只提供校准背景，不用一个平均值断言每位中国人都遵循同一种预算、家庭结构或观念。
- 内地法制与市场节点不自动外推香港、澳门、台湾。尚无充分分地区史料的项目明确保留模型标记。

## 2. 家庭文化如何进入游戏

现有 12 类情景覆盖春节团聚、升学期待、稳定职业、婚姻话题、生育期待、住房与成家、父母照护、子女成长、人情来往、异地工作、祖辈照护、亲属经济互助。每类有三语标题、说明、选择和来源。年龄、在校、工作、伴侣、子女、存活父母及冷却期决定能否出现。

春节团圆和代际传承有正式文化资料支持；具体家庭怎样团聚仍有差异。参见[重庆市政府中文报道](https://www.cq.gov.cn/ywdt/jrcq/202412/t20241208_13870992.html)及[联合国教科文组织项目说明](https://ich.unesco.org/en/RL/spring-festival-social-practices-of-the-chinese-people-in-celebration-of-traditional-new-year-02126)。

家庭教育采用陪伴、沟通、尊重个体差异的情景背景；2022 年起施行的法律也支持这些原则。参见[家庭教育促进法全文](https://www.beijing.gov.cn/zhengce/zhengcefagui/qtwj/202305/t20230505_3087270.html)。照护情景参考[老年人权益保障法](https://www.gov.cn/zhengce/2012-12/28/content_2602283.htm)，不把照护责任自动分派给女性。

文化事件允许接受、协商、拒绝或选择替代安排；不自动触发结婚、怀孕、迁居、借贷或职业录用。所有家庭成员都不能因为性别被强制绑定某种人生。涉及费用的效果用 `moneyRatio` 表示相对当地模型典型年收入的比例；钱不够时调用 `spend` 失败，不生成消费贷款。

## 3. 岗位与职业准入

目录包含农业、工人、技工、运输、餐饮、零售、照护、平台配送、国企、私企、教师、医疗、科研、公共文化、公务员、个体经营等 50 余种岗位。职业名称参考[2022 年版职业分类大典发布说明](https://chinajob.mohrss.gov.cn/h5/c/2022-10-08/361551.shtml)，不是完整的全国职业分类大典。

岗位对象包含 `id/name/educationRank/sector/entry/minYear/maxYear/minAge/multiplier/retirementCategory/sourceKeys`。学历级别为初中 2、高中或中职 3、专科 3.5、本科 4、硕士 5、博士 6。`minYear` 主要表示游戏内该种现代就业入口开放年份，并不声称此前没有相同劳动。

## 4. 消费选择与时代门槛

2025 年全国居民消费中，食品烟酒占 29.3%、居住占 21.7%、教育文化娱乐占 11.8%；这不支持“所有中国人日常支出大部分是买房”的断言。参见[国家统计局 2025 年收入消费数据](https://www.stats.gov.cn/sj/zxfb/202601/t20260119_1962321.html)。购房是资产购置，和日常居住服务分开记录；参见[国民经济核算指标解释](https://www.stats.gov.cn/sj/zbjs/202302/t20230202_1897108.html)。

商品覆盖家具、家电、装修、住房、汽车、自行车、学习用品、子女成长、继续教育、职业课程、父母照护、托育、婚礼、医疗、聚餐、旅行、通信设备和电脑。历史门槛与家庭条件同时筛选，不能 1950 年购买智能手机或股票。

| 项目 | 目前使用的时间与实际行为 |
| --- | --- |
| 家具、自行车、一般照护和学习用品 | 从游戏起始 1950 年可出现，但仍要求年龄、家庭或在校条件。 |
| 家电、全款住房 | 1980 年为现代家庭购置机会的简化入口，不声称此前不存在家电或买卖住房。 |
| 住房按揭 | 1998 年后才开放内地一般按揭入口；当年停止实物分配是逐步实施的改革，不是“此前绝无私人住房”。参见[住房改革通知](https://zjw.sh.gov.cn/wjhb/20180912/0011-30557.html)。 |
| 家庭汽车 | 1985 年为私人家庭用车的示意性入口；全款购买、资产折旧、年度使用维护支出，没有自动车贷。 |
| 通信设备 | 1985 年模型是固定电话；1987 年广州可购买昂贵的早期移动电话，其他城市到 1995 年才使用统一的移动电话入口；2000 年功能机，2010 年智能机。这些普及门槛属于年粒度近似。1987 广州商用节点见[政府通信发展资料](https://www.mva.gov.cn/sy/zt/jdbn/qhxzc/202106/t20210624_48292.html)，2010 年行业背景见[工信部统计公报](https://www.miit.gov.cn/gxsj/tjfx/txy/art/2020/art_55e8ca61f0f44b33bf832a5c748ee872.html)。 |
| 家用电脑 | 1990 年为示意性个人购置入口，不代表全国普及或首次发明。 |
| 家具、家电、装修、通信设备 | 分别采用 6、7、10、5 年更新冷却期，避免每年重复购买同一种耐用品刷属性。 |
| 继续教育 | 付款后建立三年学习安排，不立即发学历；最终结业由教育模块处理。 |

费用使用当前模型典型年收入的比例、年收入倍数、住房资产比例，或固定购买力价格。固定金额也属于统一计价下的示意购买力，不是 1950—2026 年历年实际零售价。婚礼和房产不作为结婚的硬条件，子女成长支出不重复收取已经免除的义务教育学杂费。

内地按下列来源节点开放入口：

| 入口 | 年份 | 含义与来源 |
| --- | --- | --- |
| 银行存款 | 1950 | 游戏默认储蓄方式；不是存款制度首次出现年份。 |
| 国债 | 1981 | 恢复国库券发行；不是历史上第一次发行债券。[证监会资本市场发展报告](https://www.csrc.gov.cn/csrc/c100028/c1002839/1002839/files/%E3%80%8A%E4%B8%AD%E5%9B%BD%E8%B5%84%E6%9C%AC%E5%B8%82%E5%9C%BA%E5%8F%91%E5%B1%95%E6%8A%A5%E5%91%8A%E3%80%8B%E6%91%98%E8%A6%81.pdf)。 |
| 股票 | 1990 | 沪深交易市场营业的普通投资入口近似，未抹去更早的股份制和股票试点。同上。 |
| 证券投资基金 | 1998 | 金泰、开元标志规范证券投资基金发展，早期表示封闭式基金，不声称之前完全没有任何基金。[深交所研究资料](https://www.szse.cn/aboutus/research/secuities/documents/t20040106_531397.html)。 |
| 便利基金组合 | 2001 | 以境内首只开放式基金华安创新为时代背景，组合入口本身是玩法设置。[华安基金发展历程](https://huaan.com.cn/overview.shtml)。 |

`investmentAvailable(id,year,'mainland')` 返回布尔值，其他地区返回 `null`，要求调用层单独决定。经济模块对香港股票从游戏起始年可见、台湾股票从 1962 年可见，分别参照[港交所市场历史](https://www.hkexgroup.com/about-hkex/about-hkex/history-of-hkex-and-its-market?sc_lang=en)和[台湾证券交易所历史](https://www.twse.com.tw/en/about/company/history.html)。澳门跨市场股票 1990、港澳台债券 2000、基金 2001 等目前是保守的游戏可获得性假设，不是当地首次发行年份或法律限制；可通过 `life.regionInvestmentYears` 覆盖。

存款、债券、基金、股票回报率及波动是资产风险模型，非真实收益数据或投资建议。历史模块可以叠加收益冲击；不可用或旧存档中超前的投资方式会回到存款。

## 6. 现金、助学贷款和住房贷款算法

### 现金与普通费用

`spend(life,amount,purpose)` 先检查现金，余额不足返回 `false`；从不自动借贷。年度生活短缺通过家庭支持、示意性救助、缩减开支和物质困难状态处理，不能变成负现金后自动滚利。旧存档负现金被纠正到零，并保留迁移标记，不能冒充一笔新发放的合法贷款。

首次就业前只有经审批且符合政策的国家助学贷款可以新增债务。无工作不能借住房贷款是本作保守信用规则，不冒充现实中对所有人的法律绝对禁令。已有家庭支持、奖助金和储蓄先用于费用，不因为学生零工资就每年借满上限。

### 国家助学贷款

教育模块决定是否录取、困难认定、是否申请、审核以及学费方案；本模块只做年度结算。就学数据为 `school.stage/endsAt/annualTuition/livingCost/familyContribution/scholarship/financialNeed/loanApproved/loanCap/studyRegion`。必须属于专科、本科、硕士或博士，当前地区及年份有可用政策，且完成审批和困难认定。

每学年借款为“合规费用－已可用现金、家庭支持和奖助”的实际缺口，并受当年年度上限与已借金额约束；未用完额度不自动发放。校内贷款的生活费适用范围直接读取法律模块的 `mayCoverLivingCosts`，不能错误地声称所有 2021 年前国家助学贷款都不支持生活费。参见[教育部 2005 年问答](https://www.moe.gov.cn/moe_879/moe_1252/s6035/s6038/s2992/moe_1238/tnull_13370.html)。

贷款保存在 `life.loans.student`，并以 `life.studentLoan` 为兼容别名；`borrowedByYear` 防止同学年重复借款。具体试点城市、1999/2000 推进、各期额度以及贴息条件由 `studentLoanPolicy` 提供，内地政策不自动套用港澳台。

毕业后的还本宽限期按历史政策采用 2015 年前 2 年、2015 年起 3 年、2020 年起 5 年。2020 政策同时把期限调整为学制加 15 年、最长 22 年；2015 时为学制加 13 年、最长 20 年。参见[2015 年教育部说明](https://www.moe.gov.cn/jyb_xwfb/s5147/201507/t20150716_194047.html)、[2020 年教财〔2020〕4号](https://www.moe.gov.cn/srcsite/A05/s7505/202007/t20200721_474049.html)。

实际合同的生源地与校园地、签约年份、利率与展期各有差异。本作统一简化为年度结算：在校按政策贴息，毕业宽限期内先付息，宽限期后按模型剩余期限分摊本金；模型借款利率固定 2%，不冒充合同或 LPR 报价。未支付利息只留在已经明确存在的学生贷款中，不生成消费负债。`modelGraceYears` 与 `modelRepaymentDeadline` 便于审查这些假设。

### 住房贷款

申请必须成年、已经工作、当前有稳定岗位与收入、首付款足够，并通过本作偿付能力约束。内地历史依据可见[1998 年个人住房贷款管理办法](https://www.pbc.gov.cn/zhengwugongkai/attachDir/2025/11/2025111818124023036.pdf)，但本作没有把其中历史首付比例当作 2026 年各地普遍现行标准。

模型使用首付 30%、房价为当地典型年收入的 6—16 倍、总年度债务支付不超过稳定年收入 40%、本金不超过稳定年收入 12 倍；期限和利率按时代简化。这些均为游戏信用参数。无足够首付或无工作只能储蓄，不能按下按钮凭空获得房产和无条件贷款。全款购房可以使用已有储蓄，不要求先就业。

住房贷款保存在 `life.loans.mortgage`。学生贷款与房贷分账还本付息，`life.debt` 始终是两类显式贷款余额之和。还贷困难保留欠款与协商提示，不从现金账户扣成负数。房产价格、汽车折旧及汽车维护支出也是模型参数。

## 7. 与引擎的接口

- `ensureEconomyState(life)`：补齐账户，迁移旧状态，维护贷款别名与债务汇总。
- `economyYear(life,env)`：只对当前年份结算一次；收入、家庭支持、奖助、生活教育费用、贷款、还款和收益统一结算。在年龄增长和毕业处理之前调用。
- `getEconomyShopItems(life)`：返回当时可见商品、成本、可支付状态和原因。
- `purchaseEconomyItem(life,id,env)`：实际购买；支持旧 ID `meal/trip/course/health/phone/computer/car/house/donate/adultstudy/invest-*`。
- `spend(life,amount,purpose)`：其余事件统一使用的有现金约束的支出入口。
- `canBorrowHousing(life,amount,annualPayment)`：保守贷款能力模型。

`env` 接受 `log/effects/chance/normal/integer`，日志及效果按引擎的 `(life,...)` 签名调用。历史环境通过 `env.context` 或 `life.marketContext` 传入 `incomeMultiplier/livingCostMultiplier/investmentReturnShock/housePriceShock`。失业风险由职业模块处理，经济模块不重复抽签。

`lastCashflow` 分列劳动和退休收入、伴侣贡献、家庭支持、奖助、基本救助、实际生活支出、生活缺口、教育支出、教育缺口、新增助学借款、学生还款、房贷还款、利息、收益和现金变动。`carRunningCost` 是生活预算中车辆使用成本的子项，不应重复加总。

`life.everWorked` 与 `contributionYears` 由职业模块在真实进入岗位及工作年度维护，经济模块不重复累计社保年限。退休现金收入使用 `pension + basicSupport`，基本支持不冒充已获得职工养老金。

在职工资还需要跟随城市的历史发展：每年先把岗位工资乘以“当年 `profile.typicalIncome` ÷ 岗位保存的上次 `marketIncomeReference`”，再计算岗位经验、专注和晋升变化，之后更新收入基准。这样从较早年代进入岗位的人不会永远停留在入职年的经济水平。这个指数属于体感购买力模型，不能当作 1950—2026 年真实名义工资统计。历史事件的短期收入冲击另乘在本年实际收入上，不重复写入长期基准。新岗位和旧存档没有有效基准时，直接使用当年值建立基准，不一次补涨几十年工资。迁居时若引擎已经调整工资，必须同步该基准，避免下年重复调整。养老金和基本支持不会沿用这个工资增长公式。

## 8. 验证与剩余精度限制

`tests/china-society.test.mjs` 检查三语、来源、选择权、岗位多样性、市场历史门槛与消费分类。`tests/economy.test.mjs` 检查现金不会负、未就业普通支出不借款、助学贷款实际缺口及年度限额、审批要求、贴息和毕业还款、住房偿付约束、时代商品门槛、耐用品冷却、三年继续教育、通信设备演变、汽车费用、历史冲击、工资基准增长与下降、旧工资迁移，以及养老金不套用工资增长。

本模块仍是可审查的年粒度人生模型，不是逐日法律检索系统、完整各地银行政策库、全国各行业历史工资面板或居民偏好调查。后续新增数据应保留原始来源、适用地区与年份，避免把一个全国节点写成每座城市同时生效，也避免把某种传统观念写成每个人的固定心理。
