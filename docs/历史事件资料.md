# 历史事件、城市发展与个人风险模型

核对截止日期：**2026-10-25**。收录 **100 条选编事件：国家 37 条、地区/城市 39 条、全球 24 条，55 个官方资料来源**。游戏文本提供简体中文、繁体中文和英文。1950—2026 年每一年都有连续发展阶段，没有可靠逐日事实的年份通过阶段背景覆盖，不编造“每个城市每年必有大事”。

这是可离线使用的游戏情景库，不是全部中国城市的完整地方志。地点目录覆盖与历史资料覆盖是两个不同范围。后续可继续扩充具体城市经济、教育、公共卫生和灾害资料；全国平均不等于城市实测统计。

## 文件与接口

- app/data/history.js：事实、三语叙述、作用地域、持续期、来源与明确标注的游戏参数。
- app/history-runtime.js：日期推进、居住地匹配、存档防重、独立个人结局与连续经济背景。
- app/data/development.js：国家统计局、卫健委观测锚点及单独声明的插值、城市和性别调整。
- tests/history.test.mjs：来源、逐年覆盖、时间过滤、迁居、重载和风险边界测试。
- research/china-history/build-history.py：三语数据生成器；繁体转换沿用本项目保存的 OpenCC 字典，英文为本项目简述。
- research/china-history/prc-chronology-2019.html 和 .txt：政府网大事记研究快照，仅研究使用，不在游戏内整篇转载。

运行时不请求网络：

~~~js
import {
  ensureHistoryState, processHistory,
  historicalContext, historicalProfile
} from './app/history-runtime.js';

ensureHistoryState(life);
const result = processHistory(life, calendarYearFraction, {
  log, effects, chance, normal, integer, die
});
const context = historicalContext(life);
const profile = historicalProfile(life.location, life.sex, life.world, life.year);
~~~

processHistory 返回 {changed,dead}。calendarYearFraction 是当前**日历年**的 0—1 进度，不是从生日开始的周年；引擎应在年度结束、前端进度更新和搬家之前调用。env.log(life,text,type,effects) 应应用属性变化并返回日志对象，便于附加资料来源；兼容无返回值但把对象写入 life.log[0] 的旧实现。死亡交给 env.die(life,cause,metadata)，引擎负责结算归档。

life.history 可序列化。seen 记录已走过的全部事件窗口，experienced 记录当时所在地匹配的事件，eraSeen 记录已解释的发展阶段。读取旧存档会补默认结构，已处理的事件不重播；出生月和日缺失时分别默认 1 月、1 日。

historicalContext 中收入和生活费使用乘数，投资冲击、失业与教育机会使用加法并设上限。health、happiness、relationships 仅解释汇总，瞬时变化已经应用，年度代码不得再次叠加。context 不输出 deathRisk、injuryRisk、homeLossRisk，防止每次刷新重复抽签。

## 事实与参数边界

日期、名称、地点、官方震级/深度与汇总伤亡属于事实。收入、房损、个体伤病及死亡抽签均是**游戏情景参数**。没有居民当时精确坐标、建筑抗震等级、楼层、出行、救援与就医资料，不能声称模型给出了实测个人风险。

确定到日的事件按日触发；确定到月的条目只显示 YYYY-MM，到该月总结时触发；只有年份的条目只显示 YYYY，到年度总结时触发。数据的 01-01 可能只是年份索引占位，必须读取 datePrecision，不能冒充精确事发日。

地区事件使用角色**事发时的居住地**。出生在雅安、后来住成都，不因出生地终身遭遇雅安灾害；灾后迁入也不会追溯经历已经结束的地震。开放、基础设施等持续背景可以影响后来迁入者。地级市范围仍很粗，不能把全市等同震中。

伤病、住房/物品受损、死亡分别抽签。房损降低已有房产模型价值，只消耗有限的正现金；房贷不会因房损自动免除，没有现金的人也不会凭空新增借款。没有自有房屋的人可经历家庭临时安置，叙述不声称其拥有房产。全球远方灾害影响信息、物价与互助观念，不把海外灾区死亡率套给本地居民。

## 芦山地震核对

北京时间 **2013-04-20 08:02**，四川雅安芦山县发生 **7.0 级地震，震源深度约 13 千米**，见[政府网应急报道](https://www.gov.cn/jrzg/2013-04/22/content_2385021.htm)。汇总伤亡采用较晚的[应急管理部回顾](https://www.mem.gov.cn/xw/bndt/202004/t20200420_351685.shtml)：196 人遇难、218.4 万人受灾，没有把早期速报的临时数字当作最终值。

lushan2013 匹配当前居住地 cn-511800，保存时刻、震源深度、经纬度、汇总资料日期和粗尺度暴露说明。保守情景参数为死亡 0.00012、伤病 0.025、住房/物品受损 0.055，三者独立。它们**不是官方个体概率，不能用遇难人数除以全市人口证明其精确性**，更不能设为“全雅安市居民大概率死亡”。

不同灾害参数可以不同，例如唐山强震的死亡情景权重明显高于芦山。香港山竹条目不设置死亡概率。遇难、受灾与受伤是不同口径，不能混成同一分母。

## 连续发展阶段

下表指数均为情景校准，不是每个城市实测 GDP、医疗水平或升学率。收入采用固定购买力游戏金额，不能直接对照某年人民币票面工资。全国城镇化、寿命观测点保存在 development.js，城市、性别与个人风险调整仍标模型。

香港、澳门、台湾不套用大陆“十年动乱”等制度阶段，时代概况使用独立标记的地区情景参数，不冒充当地官方历史统计；地区事件仍依各自事实匹配。historicalProfile.dataKind 区分大陆观测锚点加模型与地区情景模型，sourceIds/sourceUrls 提供来源。2026 年条件暂用最近公布的 2025 观测点与模型，标记为推算。

2026 年事件只收录截至核对日已经发生的事实，如已公布的十五五规划；未来目标没有写成已实现成果。2027 年及以后不生成历史事件，未来条件仅为明确标注的情景延伸。
