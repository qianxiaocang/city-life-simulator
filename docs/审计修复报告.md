# 此生 1.2：历史真实性与机制审计修复报告

本报告记录 `game-audit/AGENTS.md` 要求的 B0—B5 执行结果。脚本以 `GAME_SRC` 指向本项目 `app/`。原有 13.7 万局审计与本次每批 6 万局回归，均为**游戏引擎无头模拟**，不是浏览器逐局点击。浏览器验证仅用于界面与部署冒烟检查。每次引擎突变调用之后检查状态，断言同时记录失败数、分母及未覆盖数；分母为零不会被写成通过。

## 交付与重现

- 游戏源码在 `app/`；单文件 `dist/standalone.html` 可本地打开，`dist/index.html` 及其配套文件可放到静态服务器；两个 ZIP 及 SHA-256 清单位于 `release/`。
- 各批原始 JSON、抉择分叉和提交说明在 `game-audit/results/B0` 至 `B5`。`B4-final` 保存修订后针对性检查；`B5` 是最终组合代码的全量回归。`B0/度量修正说明.md` 逐项解释原指南与原校验器的错误。
- 无头回归：`GAME_SRC=/本项目/app AUDIT_OUT=/本项目/game-audit/results/B5 N=60000 node game-audit/run-audit.mjs`。完整运行需要约两三分钟；快速测试用 `node --test`。
- 发布包的 HTTP 首页、游戏脚本与单文件均返回 200；浏览器实测出生、推进、托管、英文切换和本地存档恢复，控制台错误为零。浏览器自动化环境禁止访问 `file://` 协议，所以未能在该环境直接双击验证单文件；单文件已完成构建、ZIP 完整性与 SHA-256 校验。

## 关键口径与结果

最终完整分母、失败数和未覆盖数以 `game-audit/results/B5/audit-results.json` 和同目录 `提交说明.md` 为准。最终 60,000 局中的常规断言全部通过：时间线与有限状态各 0/10,386,473 违规，选项描述 0/8,461,243 缺失，就业年龄 0/153,355 违规，退休年龄 0/34,527 违规，婚龄 0/53,629 违规，现金流对账 0/60,000 违规。养老金替代率 p50=0.3800008。每项未覆盖数单列在 JSON 中，不能视作有效分母。

本次对全部 100 条历史事件使用匹配地点和年份进行定向触发测试，100/100 可达，100/100 有事发地与机械效果；随机局中自然触发 99/100，极稀有的地方事件未自然抽中不可与不可达混同。66/66 职业在全量样本中任职。12 条家庭文化事件的终身曝光率在 30.1%—85.6%，均在指南要求的 25%—90% 区间。

分叉实验使用同种子克隆，只强制改变一个抉择，其余人生自动完成。最终 21 类抉择的宽松指纹差异率均不低于 60%，最低一类为 61.7%，共 3,667 个抉择点；即时效果重复选项为 0/3,667；对 180 个迁居点，寿命差 p95 为 3 年，低于 4 年阈值。分叉指纹包含工作、学历、家庭、财富、平均健康与幸福、照护/学习时数、反思和爱好；即时向量包含待处理升学资金、学校层次、职业资格准备等真正可观测状态。不能只以最终净资产判断选项是否有效。

`probe-house.mjs` 在 3,000 局中让角色于 24—38 岁主动购买可负担住房：39 岁仍存活的 2,788 人里，1,610 人已有房产，率为 57.7%。这不是现实住房自有率，也不是无主动购物的自动应答模式拥有率。`econ2.mjs` 核对收入、生活支出、资产、负债及家庭转移后，浮点残差在约 ±0.000001 元内。

## 仍未达标与原因

1. **D-22 出生人口权重**：1,152 个地点包含上级城市与下辖县级市/区、台湾县市与乡镇市区、香港整体与18区、澳门整体与传统堂区，存在地理重叠；本地资料只有行政名录，没有口径一致的 2020 常住人口/出生人口表。`population` 仍为 `null`，`weight` 仍为游戏抽样权重；真实人口覆盖为 0/1,152，800 个独特人口权重指标未通过，TVD 没有可信分布作分母而标 `NOT_CHECKED`。不通过给游戏权重加噪声来伪造“真实人口”。若将来补录，须先定义互斥的叶子地点、分别核对大陆/台湾/香港/澳门的统计年份和行政边界，再计算人口归一化抽样及 TVD。详见 `data-sources.md`。
2. **D-14 2026 单年三通道指标**：14 个时代段中，13 个各有收入、教育和迁居成本的事件传导；2026 只有已核实的规划公布事件。规划目标不是已经实现的收入或教育机会，因此不把它硬写成实际工资提升。`ERA_EFFECT_DIVERSITY` 为 13/14，通过 100 条事件的机械效果测试不代表这项多样性指标已通过。等待可核实的 2026 已实施政策或完整年度资料，再补对应的模型化个人传导。

另外，四地法律历史未逐年完整复原。当前官方资料支持的门槛与养老金资格独立编码；没有完整逐年条文证据的早期区间以及个人金额、风险、录取线均明确属于 `modelOnly`。2026 的完整统计尚未形成，界面将其显示为截至 2025 年观测锚点的推算情景。

## 指南口径纠正

原指南有几处不能照抄：九年义务教育为小学加初中，不包括高中；中国大陆一般就业最低年龄是 16 岁，16—17 岁受未成年工保护；“无工作一律不得贷款”并非普遍法律禁令，本游戏采用保守信用规则。历史灾害按事件当时居住地暴露，而非出生地。养老金替代率 p50 保持约 0.38，逐年时间线、早期寿命锚点和高考停招闸门继续检验。上述校验器修正和可复现种子详见 `B0/度量修正说明.md`。
