# 1.3.0：追思馆与移动端改版

首页只提供开始或继续人生、出生设置、三语切换、明暗主题和最近两段已完成人生的预览。玩法说明、导航菜单、史料年表、模型面板、存档导入/导出与消费商店均已从界面移除；资料仍保留在项目文档中。

追思馆读取原有 `this-life-city.v1` 存档中的 `history`，无需迁移旧记录。列表与人物详情分别由 `renderArchive()` 和 `renderReport()` 渲染。详情按年龄挑选出生、求学、工作、家庭、迁居等片段，再按时间顺序展示完整记录。烛光与留言写回同一条人生。最多保存最近 12 段已完成人生，记录属于当前浏览器，清除网站数据会移除它们。

`engine.js` 的 `financialDecision()` 在成年后的每四岁节点提出财务抉择，持续到 75 岁之前。候选来自 `getShopItems()`，继续沿用年代、年龄、家庭需要、现金与贷款资格限制；以提供次数轮换两项消费/教育照护和一项投资，避免反复出现同一商品。维持现有安排不会改变资金。自动人生只自动安排重心和回答抉择，购置也经过同一选择路径。

`accounting.js` 中的 `noteAssetChange()` 与 `noteCashChange()` 记录资产估值和现金变动。购置、房产/车辆重估、退休账户积累及提取、年度现金变化都写入人生记录。账目计算与记录文案独立，避免把借款或资产购置错误归作收入。投资继续使用原有单一收益方式模型，未新增独立证券账户。

界面以手机操作为优先：开始页与追思馆内容居中、卡片单列，片段使用两列小图；大屏时追思馆扩展为两列。游戏速度和推进按钮位于手机底部，记录及抉择位于上方。

运行与发布仍使用 `npm run build`：`dist/standalone.html` 为包含样式与脚本的单文件，`dist/` 可作为静态站点部署。验证和截图见根目录 `design-qa.md` 及 `qa/verification-v1.3.md`。
