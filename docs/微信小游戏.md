# 微信小游戏

`minigame/` 是可直接导入微信开发者工具的原生小游戏项目，AppID 为 `wxf0a6d9946d36da31`。入口 `game.js` 使用 `wx.createCanvas()` 绘制界面并接收触摸操作；人生引擎、事件数据、存档格式、图片生成和音乐与小程序版共用源码，由构建脚本同步。原有 `miniprogram/` 仍是独立的小程序项目。

## 构建与导入

需要 Node.js 20 或更新版本：

```sh
npm install
npm run build:minigame
npm run test:minigame
```

打开微信开发者工具，选择「导入项目」，目录选仓库中的 `minigame/`，项目类型选「小游戏」，使用上述 AppID。构建会生成 `minigame/lib/` 和 `minigame/runtime/controller.js`，并检查小游戏主包小于 2 MiB。修改共享人生逻辑或小程序控制器后，重新运行构建命令。

## 界面与功能

小游戏使用 Canvas 实现首页、出生登记、人生总览与记录、人生抉择、追思馆、人生详情和结局页。支持触摸滚动、人生托管与倍速、收藏人生瞬间、本地存档、五首背景音乐、出生卡转发、纪念照片保存到相册。首次保存会先展示相册权限说明。

界面保留小程序版的浅色和深色两套配色。首页使用组合设置控件与双列横滑馆藏；人物详情展示双列人生瞬间，档案展示身份、家人、资产、同龄人物、年份格和存活曲线。触摸滚动带减速惯性，卡片按压提供反馈，固定导航和弹窗标题外的内容不会误接收点击。

存档留在当前微信客户端的本地空间。开发者工具模拟器可以验证启动和交互；相册权限、系统转发面板及真机性能仍需在微信真机预览中确认。
