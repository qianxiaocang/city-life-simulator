# 《14亿分之一》微信小程序

小程序 AppID：`wxd60ef0cc4d0a579e`。项目使用微信原生 WXML、WXSS、Page 和本地存储；模拟引擎与网页共用源码，运行时不依赖网页、浏览器 DOM 或外部服务器。

## 构建与导入

在仓库根目录运行：

```sh
pnpm install
pnpm build:mini
pnpm test:mini
```

微信开发者工具选择“导入项目”，目录选择本仓库根目录（包含 `project.config.json`），使用上述 AppID。`miniprogramRoot` 指向 `miniprogram/`。编译入口为 `pages/index/index`。

如已安装开发者工具，也可用：

```sh
/Applications/wechatwebdevtools.app/Contents/MacOS/cli open --project "$PWD"
```

修改 `app/` 中的游戏引擎、历史、经济、职业、教育、生活事件后，需要重新运行 `pnpm build:mini`；修改 `miniprogram/pages/` 原生页面后，开发者工具会重新编译。构建脚本生成 `miniprogram/lib/game.js`，避免把浏览器专属的 `app/main.js` 打进小程序。

## 已迁移的体验

- 首页过去/现在、出生年份、地区和省份、节奏、三种语言、主题、继续人生；音乐仅在首页显示，支持拖动。
- 出生资料、同龄人、开始人生。
- 人生总览收起/展开；身份、家人和资产档案弹窗，打开期间暂停，关闭后恢复先前播放状态。
- 年内进度、倍速、暂停、推进一年、下个抉择、托管人生；年龄阶段重心和其他人生抉择使用弹窗。
- 人生记录收藏、顶部反馈、死亡后生成对应像素人生瞬间。
- 死亡叙事、拍照纪念、查看这一生、当次可编辑的纪念文字。
- 用户主动放入追思馆；从追思馆查看时仅展示纪念内容；重活一遍返回首页。

## 平台差异与数据

存档保存在当前微信/开发者工具的本地存储中，与网页浏览器存档分别保存。删除小程序或清理开发者工具全部缓存可能清除存档。没有配置云数据库，也不会自动上传人生记录。

像素场景与纪念图片使用微信 Canvas 2D 生成。图片预览与保存使用微信提供的图片接口；相册权限由用户自行选择。音乐为项目内置音频，无需配置外部音频域名。

项目未调用网络接口，不需要配置请求域名。上传体验版、正式发布和微信审核属于后续发布步骤，不由本地编译测试自动执行。

## 验证范围

`pnpm test:mini` 检查小程序配置、包体积、引擎跨阶段运行与原生页面控制器的关键交互。实际微信开发者工具模拟器的验收证据记录在 `qa/mini-verification.md`；手机扫码体验仍需使用对应 AppID 的开发者微信。
