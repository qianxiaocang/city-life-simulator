## 1. 复现方式

```bash
node sync.mjs && node build-engine.mjs      # 拉线上包 + 切出可无头运行的引擎
N=10000 OUT=./out/run10k node runner.mjs    # 全量审计（63s）

```
单条复现：`OUT=./out/run100k node replay.mjs` 列出全部缺陷及其 seed；`node replay.mjs L10K-03` 回放该缺陷的第一条样本；加 `--years` 打印这一局的完整逐年推进表。

本轮基线为一万局的两倍量级样本：**10 万局**（`OUT=./out/run100k N=100000 node runner.mjs`，689.6s）。低频项（重复选项、简繁混排、高龄初婚）在一万局只有 2–3 次，统计意义不足，已改用十万局速率作为门禁的 `needsLives` 依据。
seed 必须与年代/世界观成对使用（形如 `w13@2026/now`）：同一个 seed 换个出生年就完全是另一条人生，只给 seed 无法复现。

**门禁的两条自我约束（先读这段，再看红绿灯）**

1. `node verify.mjs --selftest` 先证明尺子本身可用：语法断言必须同时「拒绝病句 + 接受改好的句子」；繁体字符集必须通过「在」这类简繁同形字的负控；`legalMarriageAge` 必须能区分男 22 / 女 20；探针必须确实观测到过目标现象（一次都观测不到的断言不算通过）。任一项 BAD → 退出码 3，后面的红绿灯一律作废。
2. 低频缺陷不允许用小样本冒充修好：`verify.mjs` 会对照本报告实测速率，样本量不足时输出 `NOT OBSERVABLE / needsLives=X`，而不是 GREEN。

**两份计数的口径差（别当成矛盾）**

`runner.mjs`（seed 族 `a<i>`）与 `verify.mjs`（seed 族 `v<i>`）是两次独立抽样，且扫描范围不同（`verify.mjs` 只统计带 `historicalEventId` 的日志行，`runner.mjs` 的统计范围更宽），所以同一条断言的绝对命中数不可直接比大小（例：L10K-01 在 runner 为 59 615，在 verify N=10 000 为 8 266）。可复现的证据是「命中的是不是同一批条目」：两边给出的实例都落在 `土地改革法公布` / `第一个五年计划开始` / `郑州特大暴雨` 这几条上。

**这套门禁尚未被证明的部分**

「修复后能转绿」目前只在 `--selftest` 的合成样本上验证（拒绝病句、接受改好的句子）；还没有真实修复版构建可跑。拿到修复版后用 `ENGINE=./你的引擎.mjs N=10000 node verify.mjs` 复验，退出码 0 才算全绿。


## 2. 缺陷清单（按可修性排序）

### L10K-01 · 历史事件文案把事件标题当名词，硬接「发生了」，标题自带动词时生成病句

- **严重度**：high｜**类别**：中文文案 / 模板拼接
- **实测证据**：589077 次命中，覆盖 58.9 次/人；实测样本：「第一个五年计划开始发生了」「第一部宪法通过发生了」「郑州特大暴雨发生了」
- **定位（按 symbol，不要按行号）**：history-runtime.js（历史条目渲染函数）+ data/history.js 的 title 字段（HISTORY_EVENTS）
- **机制推断**：模板等价于 `${年} · 你在${城市}生活的这一年，${title.zhCN}发生了。`；当 title 以「开始/通过/公布/发布/召开/成立/实施」等动词结尾时，产出「开始发生了」一类不合语法的中文
- **判据来源**：语言常识（无需外部数据） — 中文里事件名若本身是主谓/动词短语，不能再套「X发生了」（中国玩家语言直觉；可用 2 个反例自证）
- **期望行为**：渲染时按 title 的语法形态选择连接方式：名词型用「发生了」，动词型直接叙述（例：「1954-09-20 · 这一年，第一部宪法通过。」）；或为事件补充 nounPhrase 字段供模板使用
- **可执行断言**：`const bad=/(开始|通过|公布|发布|召开|成立|实施|实行|开幕|闭幕|动工|通车)发生了/; /* N lives */ assert(!badEvents.some(e=>bad.test(txt(e.text))), badEvents.filter(e=>bad.test(txt(e.text))).slice(0,3))`
- **复现 seed**：w0 @1950/past
- **GREEN门槛**：实测 5890.8 次/千人 → 0 命中只有在 N≥1 才算修好；样本不足时的绿只说明尺子不够长

### L10K-02 · 大陆专属历史事件在台湾（及部分港澳）人生里播出，违反事件表自己的 regions 字段

- **严重度**：high｜**类别**：内容一致性 / 地区闸门
- **实测证据**：2406 次；样本 id=higher-education-expansion（1999 高校扩招）region=taiwan allowed=mainland；wto-china 同样命中
- **定位（按 symbol，不要按行号）**：history-runtime.js（选事件的循环）+ data/history.js 中 HISTORY_EVENTS[].regions
- **机制推断**：引擎在渲染历史条目时没有用 life.born.region 过滤 h.regions，或过滤条件把 taiwan/hongkong/macau 当作 mainland 的超集
- **判据来源**：引擎自证（内部一致性） — HISTORY_EVENTS 自带 regions:["mainland"]，就不得在非 mainland 人生里生效（被审数据表自身；无需外部事实）
- **期望行为**：regions 非空时严格执行白名单；若确实要表达「扩招对台湾学生的外溢影响」，应在表里新增该 region 并改写为该 region 自己的叙述，而不是复用大陆条目
- **可执行断言**：`assert(life.log.filter(e=>e.historicalEventId).every(e=>{const h=HISTORY_BY_ID.get(e.historicalEventId); return !h?.regions?.length || h.regions.includes(life.born.region)}))`
- **复现 seed**：w120 @1950/past
- **GREEN门槛**：实测 24.1 次/千人 → 0 命中只有在 N≥125 才算修好；样本不足时的绿只说明尺子不够长

### L10K-03 · 超过法定退休年龄后仍会「开始新工作」，与引擎自己的退休规则矛盾

- **严重度**：high｜**类别**：法律与生命周期 / 退休
- **实测证据**：2562 次；样本 w13 65 岁成为 vocational-teacher（法定 58）、w38 59 岁 retail（法定 55）、w50 58 岁 fishery（法定 55）

- **复现 seed**：w13 @2026/now · w38 @2026/now · w50 @2026/now · w68 @2026/now
- **GREEN门槛**：实测 25.6 次/千人 → 0 命中只有在 N≥118 才算修好；样本不足时的绿只说明尺子不够长

### L10K-04 · 大陆人嘴里 retirementRule 经常给不出可用退休年龄

- **严重度**：high｜**类别**：法规表覆盖度
- **实测证据**：43872 次（大陆人生切换工作时）；对照：非大陆 7917 次属「不适用」，已单独归类
- **定位（按 symbol，不要按行号）**：data/china-law.js 的 retirementRule（category 入参）+ career.js 传入的 job.retirementCategory
- **机制推断**：被抽查到的岗位类别包含 self-employed 等；这些类别在进入退休规则查表时返回的形状里没有 ageMonths/age
- **判据来源**：引擎自证 — 同函数对 worker/female50 等类别能返回 ageMonths（src/data/china-law.js）
- **期望行为**：每个 CHINA_JOBS[].retirementCategory 都能解析出一个明确退休年龄；灵活就业/自雇应有显式规则（或明确返回「不适用」并带 reason 字段），不能返回缺字段对象
- **可执行断言**：`for(const c of new Set(CHINA_JOBS.map(j=>j.retirementCategory))) assert(typeof retirementAge({category:c,birthYear:2026,sex:'female',region:'mainland'})==='number', c)`
- **复现 seed**：w0 @1950/past · w13 @2026/now · w19 @2026/now · w22 @2026/now
- **GREEN门槛**：实测 438.7 次/千人 → 0 命中只有在 N≥7 才算修好；样本不足时的绿只说明尺子不够长

### L10K-05 · 孩子的名字直接复制父/母的「名」，甚至与母亲全名完全相同

- **严重度**：medium｜**类别**：命名 / 中国人名习惯
- **实测证据**：复用父母名 2623 例（李明轩+郑心悦→李心悦；沈明轩+吴安然→沈安然）；与伴侣全名相同 179 例（周远航/周远航、李宇辰/李宇辰）
