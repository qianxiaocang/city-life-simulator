## 4. 换算与同量纲规则（避免口径错误）

1. **游戏内金额是 `CNY-2025-model`**（引擎自述的固定购买力口径）。跨年代比较必须先做 CPI 折算：
   `real_2025(x, year) = nominal(x, year) × ∏ CPI_t (t=year+1…2025)`；缺失年份按相邻年插值，并标注"推算"。
2. **禁止**把游戏内 1970 年代的名义金额与 1970 年代真实物价直接比（引擎已声明金额不随年代贬值）。
3. 与官方收入类指标比较时，注意三种口径不同：
   - 居民**人均可支配**收入（分母含少儿/老人/非就业人口，2024 = 41 314 元）
   - 城镇**非私营单位就业人员平均工资**（口径最高，2023 = 120 698 元）
   - 城镇**私营单位**平均工资（更低，本轮未取得一手值）
   → 判定游戏内"在职者年收入峰值"时以第 2 类为上限，以第 1 类为下限区间，且必须写明用的是哪一类。
4. **出生时平均预期寿命 ≠ 已活到成年者的死亡年龄**。因此历史队列的实际死亡年龄中位数只与"引擎自报的该队列参考寿命"对比（同量纲），不得直接与官方 `e(0)` 相减定罪。
5. 普查学历指标的分母是**全部人口（含少儿）**；与模拟中"成年后 attained 学历"对比时需说明这一点。

### 7.1 A-10 《中华人民共和国义务教育法》——由 B 级升为 A 级

- 来源页：教育部「教育法律法规」栏目 <http://www.moe.gov.cn/jyb_sjzl/sjzl_zcfg/zcfg_jyfl/202110/t20211029_575949.html>（页面日期 2021-10-29）
- 取证方式：抓取页面正文并逐条核对原文（非搜索摘要）
- 法律时间线：**1986-04-12 通过；2006-06-29 修订；修订文本自 2006-09-01 施行**
- 已核对原文（逐字）：
  - 第二条：「国家实行九年义务教育制度。……**实施义务教育，不收学费、杂费。**」
  - 第十一条：「**凡年满六周岁的儿童**，其父母或者其他法定监护人应当送其入学接受并完成义务教育；**条件不具备的地区的儿童，可以推迟到七周岁。**」
  - 第二十二条：「学校不得分设重点班和非重点班。」
  - 第六十一条：「对接受义务教育的学生免收杂费的具体期限，由国务院规定。」
- **对判定的直接影响（修复方必须照此改口径）**：
  1. 免学费杂费是 **2006-09-01 之后**的义务，且免的是"学费、杂费"，不含住宿/服务性收费；
  2. 引擎对 1986 年前小学/初中收取 39/34 元**不构成缺陷**，旧版按现行法判缺陷的写法作废；
  3. 只有 2006-09-01 以后仍出现"学费/杂费"才算与法律冲突。

### 7.3 口径纠正（旧文档作废项）

| 旧写法 | 作废原因 | 本版写法 |
|---|---|---|
| 「结婚率 80.6%」 | 统计的是**伴侣出现**，不是结婚 | 伴侣出现率 85.32%；**已婚率 81.07%**（`partner.married`） |
| 「低于法定婚龄结婚 0 例」 | 旧探针把 life 传给位置参数函数 → 恒 null → **空探针** | 用位置参数重测：成婚年 0 例（有效阴性，同一函数在伴侣出现年可测出 490 例） |
| 「首次就业 p50 = 26 岁」 | 与 `firstJobAge` 不同口径 | `firstJobAge` p50 = 18 岁（past 男女同），min 18 |
| 「60+ 岁拿到学历 648 次一律时序缺陷」 | 未区分在职进修 | 拆为在职 7,029 例 / 非在职 1,246 例，仅后者可疑 |
| main.js「1,574,199 B / 17,548 行」 | 与 `build-identity.json` 不符 | **1,454,475 B**，SHA-256 `f703243c…6721c` |
| 「引擎自报男性中位退休 65 岁」 | 与同表实测 p50 冲突 | 实测 `retireAge|past|M` p50 = **63**（min 60 / max 71） |

### 7.4 永久/本轮缺口（不得写成已核实，共 6 条）

1. 1949-1977 年出生人口**绝对数**——官方从未发布，只有出生率。
2. 全国**逐年初婚年龄**——官方不存在该序列。
3. **分年龄死亡率**、**分年龄生育率**一手表——本轮未取得。
4. **高等教育毛入学率**、成人/在职教育规模——教育部页面抓取失败（404/超时），仅二手转引。
5. **CPI 定基指数逐年序列**——只有部分年份同比，无法完成 1949→2025 完整平减。
6. **城镇人口比重逐年序列**——仅确认 2024 = 67.00%（本轮尝试的 2 个猜测 URL 均失败：`t20230206_1902009.html` 404、`gov.cn/zhengce/2005-03/04/content_156036.htm` 跳首页；未取到即如实标注，**未编造**）。
