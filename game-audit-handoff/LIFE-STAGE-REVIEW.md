## 1. 总结论

**这个游戏目前不像中国人的一生，而像"一个活在当代均质社会里、寿命 80-90 岁、几乎不生育的现代人"被贴上了 1949-2026 的年份标签。**

阶段轴判定表 30 行：**PASS 2 / WARN 17 / FAIL 11**（`out/life-stage.md`，由 `node life-stage.mjs` 复现）。

6 条最要紧的：

1. **寿命起点整体偏高 9-14 岁**（FAIL）。引擎对 1950-1970 年出生队列自报出生时预期寿命中位 **79.28 岁**，而官方 1981 年才 67.77 岁、1990 年 68.55 岁、2000 年 71.40 岁。这是"人人都活到 89 岁"观感的根因。
2. **e(0) ≈ e(25)**（FAIL）。各出生年两者相差不足 1 岁（1949：77.25 vs 76.60），意味着幼年死亡风险对寿命期望几乎没有影响——与引擎自己给出的 1950 年代 86‰ 儿童死亡率互相矛盾。
3. **1949-1957 年出生队列的男性已被引擎判为 63-65 岁退休**（FAIL）。当年法定是 60 岁（国发〔1978〕104 号），而延迟退休到 63 岁是 **2025-01-01 才开始施行**的分段规则；即便叠加"弹性延迟最长 3 年"也不成立。女性最高出现 **71 岁**，超过任何一档法定+弹性上限。
4. **最该生孩子的年代反而不生育**（FAIL）。1940s 出生队列平均子女 **0.19 个**、无子女率 87.5%；1950s 队列 0.5 个。官方粗出生率同期是 18-23‰ 的高峰。方向完全相反。
5. **婚姻无法区分初婚与再婚，离婚/丧偶在数据结构里不存在**（FAIL）。引擎全文 `divorced`、`widowed`、"离异"、"分居"、"丧偶" **0 次命中**；`family` 只有 `mother/father/partner/children/siblings`。婚次 ≥2 的仅 20/4,864 人（0.41%），且其年龄中位 26 岁比初婚中位 28 岁还小；官方 2024 年离结比约 42.9%（262.1/610.6 万对）。
6. **死因构成等同均匀抽签**（FAIL）。past 75+ 五种慢病各 19.63%-20.19%，past 60-74 各 19.31%-20.70%，now 75+ 各 19.66%-20.42%——不随年代、不随年龄变化。二手官方材料（C 级）称慢性病占总死亡 88.5%、心血管病城市占 45.86%，方向冲突。

另有两条逐年推进行内部的自相矛盾（个案级，但对玩家最刺眼）：

- **退休即净资产清零**：seed `st1201`（女，1955 生，安徽省/广德市，城区）55 岁起 `netWorth = 0` 并一直为 0 到 62 岁死亡；同期 `income` 从 55 到 62 岁**恒为 8,463 元**，八年零调整。
- **18 岁同年完成高中并直接入职，无高考分支**：同一 seed 18 岁那一年 `education = high` 与 `job = 国有企业生产工人` 同时出现，随后 国有企业生产工人 → 电力供水企业技术员 → 机械设备技术员，无任何升学/升学失败事件；其 `profile.lifeExpectancy = 79.669` 但 62 岁死于癌症。
- **界面可见佐证**：游戏 UI「模型参考寿命」对 2026 年出生女孩显示 **82.6 岁**；本逐年扫描对 2013-2015 年出生队列自报 e(0) 已是 **79.5-82.0 岁**，而官方 2020 年 e(0) 为 77.93 岁——即引擎把"2020 年的寿命水平"提前给了 2015 年出生的人。

## 2. 阶段轴逐段说明（读法：引擎实测 → 官方基线 → 判定）

完整表格在 `out/life-stage.md`（30 行，自动生成，请勿手改数字）。此处给每个阶段的要点与**玩家会感知到的表现**。

### 阶段 1 · 0-6 岁
- 1 岁内死亡 6.01%（2,403/40,000）：混合队列下高于当代 4‰，方向合理；但**引擎 1950 年代自报儿童死亡率仅 86‰**，1970s 骤降到 15.7‰。缺官方历史一手序列（永久缺口，见 §4），只判 WARN。
- 出生即城镇人口占比：1940s 45.1% → 1970s 57.0% → 1990s 65.9% → 2010s 78.4% → 2020s 84.4%。官方 2024 年末常住人口城镇化率 **67.00%**（A 级）。引擎在 1990s 队列就已 65.9%，量级偏高；一手逐年城镇化率序列本轮未取到，判 WARN 不判 FAIL。
- `preschool` 完成年龄恒为 0 岁：这是占位字段，修复方**不要**把它当"上过幼儿园"的证据，也不要在报告里据此说"引擎没有学前教育"。

### 阶段 2 · 上学
- 小学完成 **恒为 12 岁**、初中 **恒为 15 岁**（min=max，四组队列完全相同）。与义务教育法"六周岁入学 + 六三制"算式一致（PASS 的算法面），但**全国零方差**且没有"未完成初中"的人群，与 2024 年九年义务教育巩固率 95.9%（更不必说 1980 年代以前）不符 → FAIL。
- 大专及以上学历记录占比 **66.4%**，而第七次人口普查每 10 万人中大学文化程度 15,467 人 = **15.47%**（A 级）。口径不同（学历获得人次 vs 人口存量），但高出一个数量级，属结构性高估 → FAIL。
- 24 岁后首次取得高等教育学历：在职 7,029 例 / 非在职 1,246 例。**上一版把 648 例不分在职一律判"时序缺陷"是错的**，本版已拆开：在职进修属正常，全日制大龄入学才可疑。
- **时代边界必须尊重**：免学费杂费条款出自 **2006 年修订**文本（2006-09-01 施行），第六十一条把免杂费具体期限交给国务院。引擎对 1986 年前的小学/初中收 39/34 元**不构成缺陷**。

### 阶段 3 · 就业
- 首次就业年龄 p50 = **18 岁**（past 男女同），min 18，未触碰 16 岁最低就业年龄红线 → PASS。旧文档写的"首次就业 p50=26"是另一口径（首次稳定职业），本版统一为 `firstJobAge` 并注明差异。
- 一生岗位起始数均值 2.38 次。
- 40 岁收入（CNY-2025-model）：1949 队列 19,793 → 1970 队列 54,917 → 1990 队列 78,528 → 2010 队列 81,893 元。对照 2024 全国居民人均可支配收入 **41,314 元**、城镇 **54,188 元**（A 级）：引擎给 1949 年 40 岁者的"2025 币值"就已有 2 万元，是否偏高取决于 CPI 定基指数，本轮缺一手序列 → 只判 WARN。
- 收入峰值：now 男 p50 131,194 / p95 530,638 元，最大 3,264,520 元。p50 与官方 2023 年城镇非私营平均 120,698 元同量级（合理），但 p95/尾部达百万级。

### 阶段 4 · 婚恋与生育
- **口径纠正（重要）**：`family.partner` 出现 = **伴侣/恋爱**，不等于结婚。真正的成婚标记是 `partner.married` + `partner.marriedYear`，婚次在 `life.flags.marriageCount`，引擎另记 `life.marriageAge`。上一版把 85.32% 的"伴侣出现率"当结婚率，本版重测**已婚率 81.07%**。
- 成婚当年未达引擎自身法定婚龄：**0 例**，且这是**有效阴性**——同一个 `legalMarriageAge()` 在"伴侣出现年"能测出 490 例未达标，说明探针能发盲。引擎的婚姻法年代分界（1981 起男 22/女 20；1950-1980 男 20/女 18）与 1980 年婚姻法 1981-01-01 施行的时间一致 → PASS（条文原文一手页仍待核）。
- 初婚年龄 p50 = **28 岁**（p25 26 / p75 31，min 21，max 55，n=4,845）。逐年（出生十年段）：1950s 28 → 1960s 24 → 1970s 25 → 1980s 26 → 1990s 28 → 2000s 29 → 2010s 29 → 2020s 29。整体"晚婚化"方向与公开报道一致，但**1950s 队列（p50 28）比其后的 1960s/1970s 更晚**，呈非单调形，需要解释或修正。
- 再婚：见 §1 第 5 条。修复方需要补的最小字段集：婚姻性质（初婚/丧偶再婚/离异再婚）、配偶生死与时间、离婚事件与时间。
- 子女数：见 §1 第 4 条。另需注意**男主人公也统计子女数**（`kids|past|M` 均值 0.552），修复时不要只按女性侧计。

### 阶段 5 · 中年
- 终局净资产 ÷ 收入峰值：now 男 p50 7.03 / p25 1.30（min −12.0）；past 女 p25 **0.00** / p50 2.62。即约四分之一的人终局几乎没有净资产积累；官方家庭资产锚点只有 C 级（央行 2019 调查：户均净资产 289.0 万元、住房拥有率 96.0%），故判 WARN。
- 退休清零个案：见 §1。

### 阶段 6 · 老年
- 退休/缴费年限/寿命/死因：见 §1 第 1、2、3、6 条。
- **终身缴费年数最高 87 年**（物理上限：16 岁就业至 63 岁退休 = 47 年）→ FAIL。计数没有以就业起始年为下界。
- 最低缴费年限 15 年（2030-01-01 起每年 +6 个月至 20 年）：引擎 `pensionEligibilitySeparate` 与 `contributionYears` 存在，但对 1949-1970 队列是否该受 2030 后规则约束，需要按退休年份分段——本轮未判，标记为待测。

**读表结论**：引擎的 e(0) 列在 1949→2015 全程只在 77-82 之间小幅波动，而官方同期从 40 岁左右升到 77.93 岁——**引擎缺失的不是噪声，是整条上升曲线**。

## 4. 本轮明确未取到、且不允许被写成"已核实"的官方数据

1. **1949-1977 年出生人口绝对数**：官方从未发布绝对数，只有出生率。任何用"某年出生 X 万人"描述 1978 年前的做法都没有一手依据。
2. **全国逐年初婚年龄**：不存在官方年度序列（只有普查/抽样口径的分省平均初婚年龄，本轮未取到一手表）。
3. **分年龄死亡率一手表**、**分年龄生育率一手表**：本轮未取得。
4. **高等教育毛入学率、成人/在职教育规模**：教育部相关页面抓取失败（404/超时），只有二手转引。
5. **CPI 定基指数逐年序列**：只有部分年份的上年同比，无法完成 1949→2025 的完整平减。
6. **城镇人口比重逐年序列**：只确认 2024 = 67.00%。

以上条目在 `official-baselines.json` 中均为 C 级，`DATA-SOURCES.md` 逐条写明"为什么没有"。

## 6. 复现方式

```bash
# 主分布（4 万局，seed st0..st39999）
node stage-collect2.mjs 40000 out/stage-engine.json
# 逐年扫描（67 个出生年 × 24 局，seed era<年>_<序号>）
node era-sweep.mjs 24 out/era-sweep.json
# 婚姻真字段专测
node marriage-true.mjs 6000
# 伴侣出现年 vs 法定婚龄（探针阳性对照）
node marriage-at-appear.mjs 4000
# 生成阶段轴判定表（缺来源即抛错）
node life-stage.mjs > out/life-stage.md
# 个案逐年推进
node stage-collect2.mjs --trace st1201 past 1955
```

`replay.mjs` / `verify.mjs` 仍用于旧缺陷集的 seed 复现；本轮新增判定全部可由上面六条命令重跑。
